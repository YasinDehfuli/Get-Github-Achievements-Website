Откройте свои достижения на GitHub.

Достижения — это значки, которые GitHub закрепляет в вашем профиле, когда вы делаете определённые вещи, например сливаете pull request'ы или отвечаете на вопросы. Этот сайт точно показывает, как получить каждый из них.

Доступные достижения

Семь значков, которые можно получить уже сегодня, от самого быстрого до самого сложного. Откройте руководство, чтобы увидеть все шаги.

ЛегкоСоло~1 минута

Quickdraw

Закройте issue или pull request в течение 5 минут после открытия.

Показать шаги (4)

  1. Вам нужно создать New Issue или Pull Request в любом репозитории, который вы хотите.

  2. Теперь вы должны написать заголовок и оставить комментарий (если хотите). а потом . Нажмите кнопку «Отправить новую проблему».

  3. Напишите любой комментарий, который вы хотите (вы также можете закрыть проблему или запрос на извлечение без комментариев.), А затем нажмите «Закрыть проблему/закрыть запрос на извлечение».

  4. Готово, теперь вы можете увидеть это достижение Quickdraw в своем списке достижений.

ЛегкоНужен 2-й аккаунт

YOLO

Слейте pull request без ревью, хотя ревьюер был запрошен.

Показать шаги (9)

  1. Во-первых, вам нужно открыть репозиторий и перейти к настройкам.

  2. Во-вторых, вам нужно перейти в категорию соавторов и в этом разделе пригласить учетную запись, у которой есть доступ к репозиторию.

  3. В-третьих, вам нужно добавить новую ветку в ваш репозиторий.

  4. Теперь вам нужно добавить файл в новую созданную вами ветку.

  5. Добавьте файл и зафиксируйте описание для него и, наконец, зафиксируйте свои изменения.

  6. Нажмите на зеленую кнопку, сравните и вытяните запрос.

  7. Добавьте приглашенного на шаге 2 в качестве рецензента и создайте запрос на вытягивание.

  8. Наконец, проверьте, что ваш рецензент, а затем нажмите «Объединить запрос на вытягивание».

  9. Готово, теперь вы можете увидеть это достижение Yolo в списке своих достижений.

СреднеНужен merge

Pull Shark

Добейтесь, чтобы 2 ваших pull request'а слили.

Следующие уровни: 16, 128 и 1024 слитых pull request'а.

Показать шаги (5)

  1. Вам нужно получить форк из репозитория (вы можете форкнуть любой репозиторий, который хотите).

  2. Когда ваш разветвленный репозиторий создается, вам нужно внести некоторые изменения в разветвленный репозиторий (любые изменения, такие как добавление нового файла или внесение некоторых изменений в коды!), После этого вам нужно перейти на вкладку запроса на извлечение;

  3. Click on create pull request button ;

  4. Теперь вы видите, что можете объединить зеленый текст, который означает, что вы можете объединить свой запрос на включение, поэтому нажмите кнопку «Создать запрос на вытягивание», чтобы успешно создать запрос на вытягивание. Затем вам нужно дождаться, пока ваш запрос будет объединен создателем репозитория.

    Вам нужно 2 объединённых пулл-реквеста, чтобы получить достижение Pull Shark.

  5. Готово, теперь вы можете увидеть достижение Pull Shark в своем списке достижений.

СреднеНужен соавтор

Pair Extraordinaire

Станьте соавтором коммита в pull request'е, который сливают. Значок получаете и вы, и ваш соавтор.

Следующие уровни: 10, 24 и 48 слитых pull request'ов в соавторстве.

Показать шаги (6)

  1. Вам нужно установить GitHub Desktop , И клонируйте свой репозиторий из Интернета. (если вы обнаружили какую-либо ошибку, вам нужно добавить свой репозиторий из вашего внутреннего файла репозитория)

  2. Клонируйте ссылку HTTPS на репозиторий и вставьте ее в текстовое поле URL.

  3. Не нужно использовать поле фильтра, просто нажмите «Новая ветка» и «Создать новую ветку» для вашего репозитория.

  4. Добавьте резюме в поле заголовка, затем добавьте описание, наконец, добавьте соавтора по имени пользователя GitHub (вам нужно просто зафиксировать файл в своем репозитории (не нажимайте файлы)).

    Предпочитаете командную строку? Вместо этого добавьте эту строку в конец сообщения коммита:Co-authored-by: Their Name <their-email@example.com>

  5. Теперь проверьте свой репозиторий на GitHub и добавьте Assignees , а затем нажмите кнопку запроса на слияние (Pair Extraordinaire предоставит обеим учетным записям (вам и соавтору)).

  6. Готово. Теперь вы можете увидеть достижение Pair Extraordinaire в списке своих достижений.

СложноНужны другие люди

Starstruck

Владейте репозиторием, который наберёт 16 звёзд. Это засчитывается, даже если потом вы передадите репозиторий.

Следующие уровни: 128, 512 и 4096 звёзд.

Показать шаги (2)

  1. Вам нужно всего 16 звезд для каждого проекта, зарегистрированного на ваше имя пользователя. Получать от других пользователей вашей организации или репозитория.

  2. Готово. Теперь вы можете увидеть достижение Starstruck в списке достижений.

СложноНужны другие люди

Galaxy Brain

Добейтесь, чтобы 2 ваших ответа приняли в Discussions публичного репозитория.

Следующие уровни: 8, 16 и 32 принятых ответа.

Показать шаги (5)

  1. Откройте вкладку Discussions любого публичного репозитория и выберите категорию Q&A (или любую другую категорию, в которой можно отметить ответ). Ответы на официальном форуме GitHub Community больше не засчитываются, так как GitHub отключил там достижения.

    Обратите внимание: ответы на собственном форуме Community от GitHub больше не засчитываются. GitHub отключил там достижения.

  2. Теперь вам нужно найти вопросы без ответа в любых категориях, которые вы хотите. и ответьте на вопросы.

  3. Напишите правильный ответ на вопрос (Ваш ответ должен быть лучшим из возможных ответов, чтобы дизайнер вопросов выбрал его в качестве представленного ответа).

  4. Вам нужно два отправленных ответа в любых категориях, которые вы хотите получить, чтобы получить достижение Galaxy Brain.

  5. Готово, теперь вы можете увидеть достижение Galaxy Brain в своем списке достижений.

ЛегкоПлатно

Public Sponsor

Поддержите open-source разработчика через GitHub Sponsors.

Показать шаги (5)

  1. (Сначала вам нужно знать, что для получения этого значка вам нужна кредитная карта и пожертвовать немного денег). Затем вам нужно сначала открыть страницу спонсоров GitHub, а затем нажать кнопку «Просмотреть ваши основные зависимости».

  2. Вы можете увидеть список разработчиков, которым вы можете их пожертвовать, здесь.

  3. После того, как вы нашли человека, которого нужно спонсировать. вы можете увидеть страницу, чтобы выбрать, сколько вы хотите пожертвовать в месяц.

  4. Здесь есть форма для оплаты, после завершения оплаты. Вы можете увидеть свой значок в своем профиле (в бета-версии на данный момент 30 стран имеют способы оплаты).

  5. Готово. Теперь вы можете увидеть достижение Public Sponsor в списке своих достижений.

Оттенки кожи 👋🏽

Некоторые значки, например Quickdraw и Starstruck, повторяют оттенок кожи ваших эмодзи. Измените его в настройках оформления.

Скройте их, если хотите

Не любите значки? Достижения в профиле можно отключить в настройках профиля.

Официальные правила смотрите в документации GitHub об отображении значков в профиле.

Играйте честно 🏁

Это руководство объясняет, как работают достижения. Пожалуйста, соблюдайте Условия использования и правила сообщества GitHub: не спамьте в чужие проекты ради значков. Лучший способ их получить — участвовать в настоящих проектах и помогать другим.
