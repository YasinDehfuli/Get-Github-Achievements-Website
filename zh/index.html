从最简单的开始 GitHub 上的原版指南 ↗

可获得的成就

今天就能获得的七个徽章，按从快到难排序。打开指南查看每一步。

简单单人约 1 分钟

Quickdraw

在打开 issue 或 pull request 后 5 分钟内将其关闭。

显示步骤（4）

  1. 您需要在所需的任何仓库中创建“新问题”或“请求”

  2. 现在你应该写一个标题并留下评论（如果你愿意的话）。然后单击“提交新问题”按钮

  3. 写下你想要的任何评论（你可以关闭问题或拉取请求，也不需要评论。），然后点击关闭问题/关闭拉取请求

  4. 完成，现在你可以在你的成就列表中看到Quickdraw成就

简单需要第二个账号

YOLO

在已请求审查者的情况下，未经审查就合并一个 pull request。

显示步骤（9）

  1. 首先，您需要打开仓库并转到设置

  2. 其次，您需要转到合作者类别，邀请一个您有权访问仓库的帐户

  3. 您需要向仓库中添加一个新分支

  4. 然后，您需要向创建的新分支添加一个文件

  5. 添加文件并提交其描述，最后提交您的更改

  6. 点击绿色按钮，比较并提取请求

  7. 将步骤2中的受邀人员添加为审查者，并创建拉取请求

  8. 最后，检查您的审查者，然后点击合并拉取请求

  9. 完成，现在你可以在你的成就列表中看到Yolo成就

中等需要合并

Pull Shark

让 2 个 pull request 被合并。

合并 16、128 和 1024 个 pull request 时可升级。

显示步骤（5）

  1. 您需要从仓库中获取分支（您可以分支任何您想要的仓库）

  2. 当你的分叉仓库创建时，你需要对分叉仓库进行一些更改（任何更改，如添加新文件或对代码进行一些更改！）之后你需要转到拉取请求选项卡

  3. 点击创建拉取请求按钮 ;

  4. 现在你可以看到可以合并绿色文字，这代表你可以合并你的拉取请求，所以点击创建拉取请求按钮可以成功创建你的拉申请。然后等待您的请求被仓库的创建者合并。

    你需要2个合并的拉取请求，才能获得Pull Shark成就

  5. 完成，现在你可以在你的成就列表中看到Pull Shark成就

中等需要共同作者

Pair Extraordinaire

在一个被合并的 pull request 中共同提交一个 commit。你和共同作者都会获得。

共同创作并合并 10、24 和 48 个 pull request 时可升级。

显示步骤（6）

  1. 您需要安装 GitHub Desktop , 并从网上上克隆您的仓库。（如果发现任何错误，则需要从内部仓库文件中添加仓库）

  2. 克隆仓库HTTPS链接并将其粘贴URL文本框.

  3. 不使用筛选框，只需单击“新建分支”并为仓库创建新分支

  4. 在标题框中添加摘要，然后添加描述，最后按用户名 GitHub 添加共同作者（您只需在仓库中提交一个文件（不要推送文件））

    更喜欢命令行？在 commit 信息末尾加上这一行即可：Co-authored-by: 对方姓名 <their-email@example.com>

  5. 现在检查 GitHub 上的仓库并添加转让人，然后单击“合并拉取请求”按钮（Pair Extraordinaire 将同时提供给两个帐户（您和共同作者））。

  6. 完成，现在你可以在你的成就列表中看到Pair Extraordinaire成就

困难需要其他人

Starstruck

拥有一个获得 16 颗星的仓库。即使之后转移了仓库也同样算数。

获得 128、512 和 4096 颗星时可升级。

显示步骤（2）

  1. 组织/仓库 中的其他用户收藏该项目，即可获得一颗星，您的仓库项目只需要16颗星（收藏）即可获得该成就

  2. 完成，现在你可以在你的成就列表中看到Starstruck成就

困难需要其他人

Galaxy Brain

在公开仓库的 Discussions 中有 2 个回答被采纳。

有 8、16 和 32 个回答被采纳时可升级。

显示步骤（5）

  1. 打开任意公开仓库的 Discussions 标签页，并选择 Q&A 类别（或其他可以标记答案的类别）。GitHub 官方 Community 论坛已关闭成就功能，因此在那里的回答不再计入。

    注意：在 GitHub 官方 Community 论坛中的回答不再计入。GitHub 已在那里关闭了成就。

  2. 现在你需要在你想要的任何类别中找到未回答的问题并回答问题

  3. 写出问题的正确答案（你的答案必须是问题求助者选择的最佳答案）

  4. 你需要在任何类别中提交两个答案才能获得Galaxy Brain成就

  5. 完成，现在你可以在你的成就列表中看到Galaxy Brain成就

简单需要花钱

Public Sponsor

通过 GitHub Sponsors 赞助一位开源开发者。

显示步骤（5）

  1. （首先你需要知道，要想获得这个徽章，你需要信用卡和捐款）。然后你需要先打开GitHub赞助商页面，然后点击查看你的顶部附属按钮

  2. 你可以在这里看到一个开发者列表，你可以捐赠他们。（您可以得到任何在其页面上有赞助按钮的GitHub用户的赞助。）

  3. 当你找到一个人来得到赞助后。 您可以看到一个页面来选择您每月想要捐赠的金额

  4. 付款完成后，这里有一个付款表格。 您可以在您的个人资料中看到您的徽章（在 Beta 版本中，目前有 30 个国家/地区有付款方式）

  5. 完成，现在你可以在你的成就列表中看到Public Sponsor成就

肤色 👋🏽

也可以隐藏它们

不喜欢徽章？你可以在个人资料设置中关闭主页上的成就。

官方规则请参阅 GitHub 文档中关于在个人资料中显示徽章的说明。

公平参与 🏁

本指南旨在帮你了解成就的运作方式。请遵守 GitHub 的服务条款和社区准则：不要为了收集徽章去刷其他项目。获得徽章的最好方式是参与真实项目、帮助他人。
