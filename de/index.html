Schalte deine GitHub-Achievements frei.

Erreichbare Achievements

Sieben Badges, die du heute bekommen kannst, vom schnellsten bis zum schwersten. Öffne eine Anleitung, um alle Schritte zu sehen.

LeichtAllein~1 Minute

Quickdraw

Schließe ein Issue oder einen Pull Request innerhalb von 5 Minuten nach dem Öffnen.

Schritte anzeigen (4)

  1. Sie müssen in jedem gewünschten Repository ein neues Issue oder einen Pull Request erstellen.

  2. Jetzt sollten Sie einen Titel schreiben und einen Kommentar hinterlassen (wenn Sie möchten). und dann . Klicken Sie auf die Schaltfläche „Neues Problem einreichen“.

  3. Schreiben Sie einen beliebigen Kommentar (Sie können Issue oder Pull Request auch schließen, ohne einen Kommentar abzugeben). Klicken Sie dann auf Issue schließen/Pull Request schließen.

  4. Fertig. Jetzt können Sie den Quickdraw-Erfolg in Ihrer Erfolgsliste sehen.

LeichtBraucht 2. Konto

YOLO

Merge einen Pull Request ohne Review, obwohl ein Reviewer angefragt wurde.

Schritte anzeigen (9)

  1. Zuerst müssen Sie das Repository öffnen und zu den Einstellungen gehen.

  2. Zweitens müssen Sie zur Kategorie „Mitarbeiter“ gehen und in diesem Abschnitt ein Konto einladen, mit dem Sie Zugriff auf das Repository haben.

  3. Drittens müssen Sie Ihrem Repository einen neuen Zweig hinzufügen.

  4. Jetzt müssen Sie dem neu erstellten Zweig eine Datei hinzufügen.

  5. Fügen Sie die Datei hinzu, übernehmen Sie die Beschreibung dafür und übernehmen Sie schließlich Ihre Änderungen

  6. Klicken Sie auf den grünen Button, vergleichen Sie und ziehen Sie die Anfrage.

  7. Fügen Sie die eingeladene Person in Schritt 2 als Prüfer hinzu und erstellen Sie eine Pull-Anfrage.

  8. Überprüfen Sie abschließend, ob Ihr Prüfer vorhanden ist, und klicken Sie dann auf Pull-Anfrage zusammenführen.

  9. Fertig. Jetzt können Sie den Yolo-Erfolg in Ihrer Erfolgsliste sehen.

MittelBraucht einen Merge

Pull Shark

Lass 2 Pull Requests mergen.

Höhere Stufen bei 16, 128 und 1024 gemergten Pull Requests.

Schritte anzeigen (5)

  1. Sie müssen einen Fork von einem Repository erhalten (Sie können jedes gewünschte Repository forken).

  2. Wenn Ihr gespaltenes Repository erstellt wird, müssen Sie einige Änderungen am gespaltenen Repository vornehmen (Änderungen wie das Hinzufügen einer neuen Datei oder einige Änderungen an Codes!). Danach müssen Sie zur Registerkarte „Pull-Anfrage“ gehen;

  3. Klicken Sie auf die Schaltfläche „Pull-Anfrage erstellen“;

  4. Jetzt sehen Sie den grünen Text „Merge möglich“, der bedeutet, dass Sie Ihre Pull-Anfrage zusammenführen können. Klicken Sie also auf die Schaltfläche „Pull-Anfrage erstellen“, um Ihre Pull-Anfrage erfolgreich zu erstellen. Dann müssen Sie warten, bis Ihre Anfrage vom Ersteller des Repositorys zusammengeführt wird.

    Sie benötigen 2 zusammengeführte Pull-Anfragen, um die Pull Shark-Errungenschaft zu erhalten

  5. Fertig. Jetzt können Sie den Pull Shark-Erfolg in Ihrer Erfolgsliste sehen.

MittelBraucht Co-Autor

Pair Extraordinaire

Sei Co-Autor eines Commits in einem Pull Request, der gemergt wird. Du und dein Co-Autor bekommt es beide.

Höhere Stufen bei 10, 24 und 48 gemeinsam verfassten, gemergten Pull Requests.

Schritte anzeigen (6)

  1. Sie müssen GitHub Desktop installieren und Ihr Repository aus dem Internet klonen. (Wenn Sie einen Fehler gefunden haben, müssen Sie Ihr Repository aus Ihrer internen Repository-Datei hinzufügen.)

  2. Klonen Sie den HTTPS-Link Ihres Repositorys und fügen Sie ihn in das URL-Textfeld ein.

  3. Sie müssen kein Filterfeld verwenden. Klicken Sie einfach auf „Neuer Zweig“ und „Neuen Zweig für Ihr Repository erstellen“.

  4. Fügen Sie eine Zusammenfassung in Ihr Titelfeld ein, fügen Sie dann eine Beschreibung hinzu und fügen Sie zuletzt einen Co-Autor mit Benutzernamen GitHub hinzu (Sie müssen nur eine Datei in Ihrem Repository festschreiben (die Dateien nicht übertragen)).

    Lieber die Kommandozeile? Füge stattdessen diese Zeile ans Ende deiner Commit-Nachricht an:Co-authored-by: Their Name <their-email@example.com>

  5. Fügen Sie eine Zusammenfassung in Ihr Titelfeld ein, fügen Sie dann eine Beschreibung hinzu und fügen Sie zuletzt einen Co-Autor mit Benutzernamen GitHub hinzu (Sie müssen nur eine Datei in Ihrem Repository festschreiben (die Dateien nicht übertragen)).

  6. Fertig. Jetzt können Sie den „Pair Extraordinaire“-Erfolg in Ihrer Erfolgsliste sehen.

SchwerBraucht andere Leute

Starstruck

Besitze ein Repository, das 16 Sterne erreicht. Es zählt auch, wenn du das Repository später überträgst.

Höhere Stufen bei 128, 512 und 4096 Sternen.

Schritte anzeigen (2)

  1. Sie benötigen nur 16 Sterne für jedes unter Ihrem Benutzernamen registrierte Projekt. Erhalten Sie von anderen Benutzern Ihrer Organisation oder Ihres Repositorys.

  2. Fertig. Jetzt können Sie den Starstruck-Erfolg in Ihrer Erfolgsliste sehen.

SchwerBraucht andere Leute

Galaxy Brain

Lass 2 deiner Antworten akzeptieren in den Discussions eines öffentlichen Repositorys.

Höhere Stufen bei 8, 16 und 32 akzeptierten Antworten.

Schritte anzeigen (5)

  1. Öffnen Sie den Tab „Discussions“ eines beliebigen öffentlichen Repositorys und wählen Sie die Kategorie „Q&A“ (oder eine andere Kategorie, in der eine Antwort markiert werden kann). Antworten im offiziellen GitHub-Community-Forum zählen nicht mehr, da GitHub dort Achievements deaktiviert hat.

    Achtung: Antworten im eigenen Community-Forum von GitHub zählen nicht mehr. GitHub hat Achievements dort abgeschaltet.

  2. Jetzt müssen Sie unbeantwortete Fragen in den gewünschten Kategorien finden. und beantworte die Fragen.

  3. Schreiben Sie die richtige Antwort auf die Frage (Ihre Antwort muss die bestmögliche sein, damit sie vom Fragendesigner als eingereichte Antwort ausgewählt werden kann).

  4. Sie benötigen zwei eingereichte Antworten in allen Kategorien, in denen Sie den Galaxy Brain-Erfolg erhalten möchten

  5. Fertig. Jetzt können Sie die Galaxy Brain-Errungenschaft in Ihrer Erfolgsliste sehen.

LeichtKostet Geld

Public Sponsor

Unterstütze einen Open-Source-Entwickler über GitHub Sponsors.

Schritte anzeigen (5)

  1. (Zuerst müssen Sie wissen, dass Sie für den Erhalt dieses Abzeichens eine Kreditkarte benötigen und etwas Geld spenden müssen). Dann müssen Sie zuerst die GitHub-Sponsorenseite öffnen und dann auf die Schaltfläche „Ihre wichtigsten Abhängigkeiten anzeigen“ klicken

  2. Hier können Sie eine Liste der Entwickler sehen, die Sie spenden können. (Sie können von jedem GitHub-Benutzer gesponsert werden, der auf seinen Seiten über die Schaltfläche „Sponsor“ verfügt.)

  3. Nachdem Sie eine Person gefunden haben, die Sie unterstützen möchten. Sie können eine Seite sehen, auf der Sie auswählen können, wie viel Sie pro Monat spenden möchten.

  4. Nach Abschluss Ihrer Zahlung finden Sie hier ein Zahlungsformular. Sie können Ihr Abzeichen in Ihrem Profil sehen (in der Beta-Version verfügen derzeit 30 Länder über Zahlungsmethoden).

  5. Fertig. Jetzt können Sie die Leistung des öffentlichen Sponsors in Ihrer Erfolgsliste sehen.

Hauttöne 👋🏽

Manche Badges, wie Quickdraw und Starstruck, übernehmen deinen Emoji-Hautton. Ändere ihn in deinen Darstellungseinstellungen.

Ausblenden, wenn du magst

Keine Lust auf Badges? Du kannst Achievements in deinen Profileinstellungen ausschalten.

Die offiziellen Regeln findest du in der GitHub-Doku zum Anzeigen von Badges im Profil.

Bleib fair 🏁

Diese Anleitung soll dir zeigen, wie Achievements funktionieren. Bitte respektiere die Nutzungsbedingungen und Community-Richtlinien von GitHub: Spamme keine anderen Projekte, nur um Badges zu sammeln. Am besten verdienst du sie, indem du bei echten Projekten mitmachst und anderen hilfst.
