Ontgrendel je GitHub-achievements.

Achievements zijn de badges die GitHub op je profiel zet als je bepaalde dingen doet, zoals pull requests mergen of vragen beantwoorden. Deze site laat precies zien hoe je ze allemaal verdient.

Te verdienen achievements

Zeven badges die je vandaag kunt verdienen, van snelst naar moeilijkst. Open een handleiding om alle stappen te zien.

MakkelijkSolo~1 minuut

Quickdraw

Sluit een issue of pull request binnen 5 minuten nadat je het hebt geopend.

Toon de stappen (4)

  1. Je moet een New Issue of Pull Request aanmaken in een repository naar keuze.

  2. Nu moet u een titel schrijven en een opmerking achterlaten (als u dat wilt) . en dan . Klik op de knop Nieuwe uitgave indienen.

  3. Schrijf een commentaar dat u wilt (u kunt het probleem of pullverzoek ook sluiten zonder commentaar te geven) en klik vervolgens op Probleem sluiten / pullverzoek sluiten.

  4. Klaar, nu kun je het Quickdraw-prestatie in je lijst met prestaties zien.

MakkelijkTweede account nodig

YOLO

Merge een pull request zonder review, ook al is er een reviewer gevraagd.

Toon de stappen (9)

  1. Eerst moet je het archief openen en naar instellingen gaan.

  2. Ten tweede moet je naar de categorie Medewerkers gaan en in dit gedeelte een account uitnodigen waarmee je toegang hebt tot het archief.

  3. Ten derde moet je een nieuwe tak toevoegen aan je repository.

  4. Nu moet je een bestand toevoegen aan de nieuwe tak die je gemaakt hebt.

  5. Voeg het bestand toe en leg de beschrijving vast en leg ten slotte je wijzigingen vast

  6. Klik op de groene knop, vergelijk en pull request.

  7. Voeg de uitgenodigde persoon in stap-2 toe als Reviewer en maak een pull-request aan.

  8. Controleer tenslotte of je Reviewer bent en klik dan op Merge pull request.

  9. Klaar , Nu kun je die Yolo prestatie zien in je lijst met prestaties.

GemiddeldMerge nodig

Pull Shark

Laat 2 pull requests mergen.

Hogere niveaus bij 16, 128 en 1024 gemergede pull requests.

Toon de stappen (5)

  1. Je moet eender welke repository forken.

  2. Wanneer je de fork hebt gemaakt, moet je wijzigingen aanbrengen aan de forked repository ( eender welke wijzigingen, zoals een nieuw bestand toevoegen of de code aanpassen ! ). Daarna moet je naar het pull request tabblad gaan;

  3. Klik op de 'create pull request' knop ;

  4. Nu kun je groene tekst zien die betekent dat je je pull request kunt mergen, dus klik op de 'Create Pull request' knop om je pull request aan te maken. Dan moet je wachten tot je verzoek is samengevoegd door de maker van de repository.

    Je moet 2 pull requests mergen om de Pull Haai prestatie te behalen

  5. Klaar, nu kan je de Pull Haai Prestatie zien in je prestatielijst.

GemiddeldCo-auteur nodig

Pair Extraordinaire

Wees co-auteur van een commit in een pull request die gemerged wordt. Jij en je co-auteur verdienen hem allebei.

Hogere niveaus bij 10, 24 en 48 gemergede pull requests als co-auteur.

Toon de stappen (6)

  1. Je moet GitHub Desktop installeren, en je repository van het internet klonen. (als je een foutmelding vindt, moet je je repository toevoegen vanuit je interne repository bestand)

  2. Kloon de HTTPS-link van je archief en voeg deze in het tekstvak URL in.

  3. Je hoeft het filtervak niet te gebruiken, klik gewoon op Nieuwe branch en maak een nieuwe branch voor je archief.

  4. Voeg een samenvatting toe in je titelvak, voeg dan een beschrijving toe, voeg als laatste een Co-Author By Username GitHub (Je hoeft alleen maar een bestand vast te leggen in je repository (Don't Push the Files)).

    Liever de command line? Zet dan deze regel aan het einde van je commitbericht:Co-authored-by: Hun Naam <their-email@example.com>

  5. Controleer nu je repository op GitHub en voeg Assignees toe, en klik dan op de samenvoeg pull request knop (de Pair Extraordinaire zal aan beide accounts geven (Jij en Co-Author)).

  6. Klaar, nu kun je de prestatie Pair Extraordinaire zien in je lijst met prestaties.

MoeilijkAndere mensen nodig

Starstruck

Bezit een repository die 16 sterren haalt. Het telt nog steeds als je de repository later overdraagt.

Hogere niveaus bij 128, 512 en 4096 sterren.

Toon de stappen (2)

  1. Je hebt slechts 16 sterren nodig voor elk project dat onder jouw gebruikersnaam geregistreerd staat. Ontvangen van andere gebruikers van je organisatie of archief.

  2. Klaar, nu kun je die Starstruck prestatie zien in je lijst met prestaties.

MoeilijkAndere mensen nodig

Galaxy Brain

Laat 2 van je antwoorden accepteren in de Discussions van een openbare repository.

Hogere niveaus bij 8, 16 en 32 geaccepteerde antwoorden.

Toon de stappen (5)

  1. Open het tabblad Discussions van een willekeurige openbare repository en kies de categorie Q&A (of een andere categorie waarin een antwoord gemarkeerd kan worden). Antwoorden op het officiële GitHub Community-forum tellen niet meer mee, omdat GitHub daar prestaties heeft uitgeschakeld.

    Let op: antwoorden in GitHubs eigen Community-forum tellen niet meer mee. GitHub heeft achievements daar uitgezet.

  2. Nu moet je onbeantwoorde vragen vinden in de categorieën die je wilt en de vragen beantwoorden.

  3. Schrijf het juiste antwoord op de vraag (Je antwoord moet het best mogelijke antwoord zijn om geselecteerd te worden als het ingezonden antwoord door de ontwerper van de vraag).

  4. Je hebt twee antwoorden nodig in elke categorie om de Galaxy Brain-prestatie te krijgen.

  5. Klaar, nu kun je de Galaxy Brain prestatie zien in je lijst met prestaties.

MakkelijkKost geld

Public Sponsor

Sponsor een open-sourceontwikkelaar via GitHub Sponsors.

Toon de stappen (5)

  1. (Eerst moet je weten dat je voor deze badge een creditcard nodig hebt en wat geld moet doneren). Dan moet je eerst de GitHub Sponsors pagina openen, en dan op de knop See your top dependencies klikken

  2. Je kunt hier een lijst van ontwikkelaars zien die je kunt doneren. (Je kunt gesponsord worden door alle GitHub gebruikers die een gesponsorde knop op hun pagina's hebben).

  3. Nadat je een persoon hebt gevonden die je wilt sponsoren, zie je een pagina waarop je kunt aangeven hoeveel je per maand wilt doneren.

  4. Er is hier een formulier om te betalen, nadat je betaling is voltooid. Je kunt je badge in je profiel zien (in de bètaversie hebben voorlopig 30 landen betaalmethoden).

  5. Klaar, nu kun je die Publieke Sponsor Prestatie zien in je lijst van prestaties.

Huidskleuren 👋🏽

Sommige badges, zoals Quickdraw en Starstruck, volgen je emoji-huidskleur. Pas die aan in je weergave-instellingen.

Verberg ze als je wilt

Niks voor jou, badges? Je kunt achievements op je profiel uitzetten in je profielinstellingen.

Voor de officiële regels, zie de GitHub-documentatie over badges tonen op je profiel.

Speel eerlijk 🏁

Deze handleiding is er om je te leren hoe achievements werken. Respecteer de Servicevoorwaarden en communityrichtlijnen van GitHub: spam geen andere projecten alleen om badges te verzamelen. De beste manier om ze te verdienen is mee te doen aan echte projecten en anderen te helpen.
