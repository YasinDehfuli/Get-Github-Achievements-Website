Անվճար, քայլ առ քայլ, սքրինշոթներով

Բացեք ձեր GitHub-ի նվաճումները։

Նվաճումները կրծքանշաններ են, որոնք GitHub-ը ամրացնում է ձեր պրոֆիլին որոշակի գործողությունների համար, օրինակ՝ pull request-ներ միավորելու կամ հարցերի պատասխանելու։ Այս կայքը ցույց է տալիս, թե ինչպես ստանալ դրանցից յուրաքանչյուրը։

Սկսել ամենահեշտից Բնօրինակ ուղեցույցը GitHub-ում ↗

Ստանալի նվաճումներ

Յոթ կրծքանշան, որ կարող եք ստանալ այսօր՝ ամենաարագից մինչև ամենադժվարը։ Բացեք ուղեցույցը՝ բոլոր քայլերը տեսնելու համար։

ՀեշտՄիայնակ~1 րոպե

Quickdraw

Փակեք issue կամ pull request այն բացելուց հետո 5 րոպեի ընթացքում։

Ցույց տալ քայլերը (4)

  1. Դուք պետք է ստեղծեք նոր խնդիր կամ փուլլ ռեքուեսթ ցանկացած ռեպոյի վրա, որը ցանկանում եք:

  2. Այժմ դուք պետք է գրեք վերնագիր և թողեք մեկնաբանություն (եթե ցանկանում եք) և հետո սեղմեք «Submit New Issue» կոճակը:

  3. Գրեք ցանկացած մեկնաբանություն (կարող եք նաև փակել խնդիրը կամ ուղարկել հարցումը առանց մեկնաբանությունների): Այնուհետև սեղմեք Փակել խնդիրը/Փակել փուլլ ռեքուեսթը:

  4. Պատրաստ է, այժմ դուք կարող եք տեսնել Quickdraw ձեռքբերումը ձեր ձեռքբերումների ցանկում:

ՀեշտՊետք է 2-րդ հաշիվ

YOLO

Միավորեք pull request առանց review-ի, թեև review էր խնդրվել։

Ցույց տալ քայլերը (9)

  1. Նախ, դուք պետք է բացեք ռեպո և անցնեք կարգավորումների բաժին:

  2. Երկրորդ, դուք պետք է գնաք համահեղինակների կատեգորիա և այս բաժնում հրավիրեք օգտատեր, որին դուք թույլ եք տվել մուտք գործի ռեպո:

  3. Երրորդ, դուք պետք է նոր բրենչ ավելացնեք ձեր պահեստում:

  4. Այժմ դուք պետք է ավելացնեք ֆայլը ձեր ստեղծած նոր բրենչում:

  5. Ավելացրեք ֆայլ և կատարեք դրա նկարագրությունը և վերջապես կատարեք ձեր փոփոխությունները:

  6. Սեղմեք կանաչ կոճակը, համեմատեք և փուլլ արեք ռեքուեսթը:

  7. Ավելացրեք հրավիրված օգտատիրոջը քայլ 2-ում որպես վերանայող և ստեղծեք փուլլ ռեքուեսթ:

  8. Ի վերջո, ստուգեք ձեր վերանայողին և կտտացրեք «Merge Pull Request»:

  9. Պատրաստ է, այժմ դուք կարող եք տեսնել Yolo ձեռքբերումը ձեր ձեռքբերումների ցանկում:

ՄիջինՊետք է merge

Pull Shark

Ստացեք 2 միավորված pull request։

Բարձր մակարդակներ՝ 16, 128 և 1024 միավորված pull request-ի դեպքում։

Ցույց տալ քայլերը (5)

  1. Դուք պետք է ֆոռք ստանաք ռեպոյից (կարող եք ֆոռքել ցանկացած ռեպոյից, որը ցանկանում եք):

  2. Երբ ձեր ֆոռք եղած ռեպոն ստեղծվի, դուք պետք է որոշ փոփոխություններ կատարեք ֆոռք եղած ռեպոյում (ցանկացած փոփոխություն, օրինակ՝ ավելացնել նոր ֆայլ կամ որոշ փոփոխություններ կատարել կոդերի վրա):

  3. Կտտացրեք «Create a Pull Request» կոճակին։

  4. Այժմ դուք կարող եք տեսնել, որ կարող եք «Merge» կանաչ տեքստը, ինչը նշանակում է, որ դուք կարող եք մերջ անել ձեր փուլլ ռեքուեսթը, այնպես որ սեղմեք «Create a Pull Request» կոճակը, որպեսզի ձեր փուլլ ռեքուեսթը հաջողությամբ ստեղծվի: Այնուհետև դուք պետք է սպասեք, որ ձեր հարցումը մերջ արվի ռեպոն ստեղծողի կողմից:

    Ձեզ անհրաժեշտ է 2 միավորված փուլլ ռեքուեսթ՝ Pull Shark ձեռքբերումը ստանալու համար

  5. Պատրաստ է, այժմ դուք կարող եք տեսնել Pull Shark ձեռքբերումը ձեր ձեռքբերումների ցանկում:

ՄիջինՊետք է համահեղինակ

Pair Extraordinaire

Համահեղինակեք commit մի pull request-ում, որը միավորվում է։ Այն ստանում եք և՛ դուք, և՛ ձեր համահեղինակը։

Բարձր մակարդակներ՝ 10, 24 և 48 համահեղինակած միավորված pull request-ի դեպքում։

Ցույց տալ քայլերը (6)

  1. Դուք պետք է տեղադրեք [GitHub Desktop] (https://desktop.github.com/) , Դուք պետք է ավելացնեք ձեր ռեպոն ձեր ներքին պահոցից:

  2. Պատճենեք ռեպոյի HTTPS հղումը և տեղադրեք այն URL տեքստային վանդակում:

  3. Կարիք չկա օգտագործել զտիչ տուփը, պարզապես սեղմեք «New Branch» և Ստեղծեք նոր բրենչ ձեր ռեպոյի համար

  4. Վերնագրի դաշտում ավելացրեք ամփոփագիր, այնուհետև ավելացրեք նկարագրություն, վերջում ավելացրեք համահեղինակ GitHub-ի ցանկացած օգտատիրոջ օգտանունով (ուղղակի պետք է ֆայլը մուտքագրեք ձեր ռեպոն (ֆայլերը փուշ մի արեք)):

    Նախընտրո՞ւմ եք հրամանի տողը։ Փոխարենը ավելացրեք այս տողը commit-ի հաղորդագրության վերջում՝Co-authored-by: Their Name <their-email@example.com>

  5. Այժմ ստուգեք ձեր GitHub ռեպոն և ավելացրեք հանձնարարվածներին, այնուհետև սեղմեք «Merge Pull Request» կոճակը (Pair Extraordinaire-ը կտրամադրվի երկու հաշիվներին (ձեզ և համահեղինակին)):

  6. Պատրաստ է, այժմ դուք կարող եք տեսնել Pair Extraordinaire ձեռքբերումը ձեր ձեռքբերումների ցանկում:

ԴժվարՊետք են այլ մարդիկ

Starstruck

Ունեցեք ռեպոզիտորիա, որը հասնում է 16 աստղի։ Այն հաշվվում է, նույնիսկ եթե հետո ռեպոզիտորիան փոխանցեք։

Բարձր մակարդակներ՝ 128, 512 և 4096 աստղի դեպքում։

Ցույց տալ քայլերը (2)

  1. Ձեր օգտանունով գրանցված յուրաքանչյուր նախագծի համար անհրաժեշտ է ընդամենը 16 աստղ: Ստացեք ձեր կազմակերպության կամ ռեպոյի այլ օգտվողներից:

  2. Պատրաստ է, այժմ դուք կարող եք տեսնել Starstruck ձեռքբերումը ձեր ձեռքբերումների ցանկում:

ԴժվարՊետք են այլ մարդիկ

Galaxy Brain

Ստացեք ձեր 2 պատասխանների ընդունում հանրային ռեպոզիտորիայի Discussions-ում։

Բարձր մակարդակներ՝ 8, 16 և 32 ընդունված պատասխանի դեպքում։

Ցույց տալ քայլերը (5)

  1. Բացեք ցանկացած հանրային ռեպոզիտորիայի Discussions ներդիրը և ընտրեք Q&A կատեգորիան (կամ ցանկացած այլ կատեգորիա, որտեղ պատասխանը կարելի է նշել որպես ընդունված): GitHub-ի պաշտոնական Community ֆորումում տրված պատասխաններն այլևս չեն հաշվվում, քանի որ GitHub-ն այնտեղ անջատել է ձեռքբերումները:

    Ուշադրություն՝ GitHub-ի սեփական Community ֆորումի պատասխաններն այլևս չեն հաշվվում։ GitHub-ն այնտեղ անջատել է նվաճումները։

  2. Այժմ դուք պետք է անպատասխան հարցեր գտնեք ձեր ուզած կատեգորիաներում և պատասխանեք հարցերին:

  3. Գրեք հարցի ճիշտ պատասխանը (Ձեր պատասխանը պետք է լինի հնարավոր լավագույն պատասխանը, որպեսզի ընտրվի որպես ներկայացված պատասխան հարցի նախագծողի կողմից):

  4. Ձեզ անհրաժեշտ է երկու ճիշտ ընտրված պատասխաններ ցանկացած կատեգորիայում, եթե ցանկանում եք ստանալ Galaxy Brain ձեռքբերումը:

  5. Պատրաստ է, այժմ դուք կարող եք տեսնել Galaxy Brain ձեռքբերումը ձեր ձեռքբերումների ցանկում:

ՀեշտՎճարովի է

Public Sponsor

Աջակցեք բաց կոդի ծրագրավորողին GitHub Sponsors-ի միջոցով։

Ցույց տալ քայլերը (5)

  1. (Նախ դուք պետք է իմանաք, որ այս նշանը ստանալու համար ձեզ հարկավոր է կրեդիտ քարտ և որոշակի գումար նվիրաբերել): Այնուհետև նախ պետք է բացեք GitHub-ի աջակիցների էջը և սեղմեք «See Your Top Dependencies» կոճակը:

  2. Դուք կարող եք տեսնել օգտատերերի ցանկը, որոնց կարող եք նվիրաբերել այստեղ: (Դուք կարող եք հովանավորվել GitHub-ի ցանկացած օգտատերերի կողմից, ովքեր ունեն հովանավորման կոճակ իրենց էջում):

  3. Այն բանից հետո, երբ գտաք հովանավորվող անձին: դուք կտեսնեք մի էջ՝ ընտրելու համար, թե որքան եք ցանկանում նվիրաբերել ամսական:

  4. Այստեղ վճարման դաշտեր կան։ Վճարման ավարտից հետո դուք կարող եք տեսնել ձեր նշանը ձեր պրոֆիլում (բետա տարբերակում 30 երկրներ առայժմ վճարման եղանակներ ունեն):

  5. Պատրաստ է, այժմ դուք կարող եք տեսնել Public Sponsor ձեռքբերումը ձեր ձեռքբերումների ցանկում:

Այլ կրծքանշաններ
