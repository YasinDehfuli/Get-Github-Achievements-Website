Unlock your GitHub achievements.

Achievements are the badges GitHub pins to your profile when you do certain things, like merging pull requests or answering questions. This site shows you exactly how to earn each one.

Earnable achievements

Seven badges you can earn today, ordered from quickest to hardest. Open a guide to see every step.

EasySolo~1 minute

Quickdraw

Close an issue or pull request within 5 minutes of opening it.

Show the steps (4)

  1. Open a new issue (or pull request) in any repository. Your own repository works fine.

  2. Give it a title, add a comment if you like, then click Submit new issue.

  3. Straight away, click Close issue (or Close pull request). A comment is optional.

  4. Done. Quickdraw appears in the achievements list on your profile.

EasyNeeds a 2nd account

YOLO

Merge a pull request without a review, even though a reviewer was requested.

Show the steps (9)

  1. Open your repository and go to Settings.

  2. Under Collaborators, invite another account you can sign in to (a friend's account also works).

  3. Create a new branch in the repository.

  4. Add a file to that new branch.

  5. Write a commit message and commit the change.

  6. Click the green Compare & pull request button.

  7. Add the collaborator from step 2 as a Reviewer, then create the pull request.

  8. Without waiting for that review, click Merge pull request.

  9. Done. YOLO appears in your achievements list.

MediumNeeds a merge

Pull Shark

Get 2 pull requests merged.

Higher tiers at 16, 128 and 1024 merged pull requests.

Show the steps (5)

  1. Fork a repository of your choice.

  2. Make a change in your fork, such as adding a file or fixing some code, then open the Pull requests tab.

  3. Click Create pull request.

  4. Submit it and wait for the maintainer to merge it. You need 2 merged pull requests.

  5. Done. Pull Shark appears in your achievements list.

MediumNeeds a co-author

Pair Extraordinaire

Co-author a commit in a pull request that gets merged. You and your co-author both earn it.

Higher tiers at 10, 24 and 48 co-authored merged pull requests.

Show the steps (6)

  1. Install GitHub Desktop and add your repository from its folder on your computer.

  2. Add the local repository, then commit and push any changed files.

  3. Click New branch and create a new branch for your change.

  4. Change a file, write a summary and description, and use the co-author button to add your partner by their GitHub username. Then commit.

    Prefer the command line? Add this line at the end of your commit message instead:Co-authored-by: Their Name <their-email@example.com>

  5. Publish the branch, open the pull request on GitHub, and click Merge pull request.

  6. Done. Pair Extraordinaire appears for both you and your co-author.

HardNeeds other people

Starstruck

Own a repository that reaches 16 stars. It still counts if you later transfer the repository.

Higher tiers at 128, 512 and 4096 stars.

Show the steps (2)

  1. Build something people find useful and share it. Once one repository under your username collects 16 stars from other users, the badge unlocks.

  2. Done. Starstruck appears in your achievements list.

HardNeeds other people

Galaxy Brain

Get 2 of your answers accepted in a public repository's Discussions.

Higher tiers at 8, 16 and 32 accepted answers.

Show the steps (5)

  1. Open the Discussions tab of any public repository and pick the Q&A category (or any category where an answer can be marked).

    Heads up: answers in GitHub's own Community forum no longer count. GitHub turned achievements off there.

  2. Find an unanswered question and answer it.

  3. Write a helpful, correct answer. The person who asked has to mark it as the answer.

  4. Get two answers accepted to unlock the badge.

  5. Done. Galaxy Brain appears in your achievements list.

EasyCosts money

Public Sponsor

Sponsor an open-source developer through GitHub Sponsors.

Show the steps (5)

  1. You'll need a payment card. Open GitHub Sponsors and click See your top dependencies.

  2. Pick a developer from the list. Anyone with a Sponsor button on their profile works.

  3. Choose how much you want to give.

  4. Fill in the payment form. Sponsoring is only available in supported countries.

  5. Done. Public Sponsor appears in your achievements list.

Skin tones 👋🏽

Some badges, like Quickdraw and Starstruck, follow your emoji skin tone. Change it in your appearance settings.

Hide them if you like

Not into badges? You can turn off achievements on your profile from your profile settings.

For the official rules, see GitHub's docs on displaying badges on your profile.

Play fair 🏁

This guide is here to teach you how achievements work. Please respect GitHub's Terms of Service and community guidelines: don't spam other projects just to collect badges. The best way to earn them is to take part in real projects and help other people.
