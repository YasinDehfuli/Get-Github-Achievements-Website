অর্জনযোগ্য অ্যাচিভমেন্ট

সাতটি ব্যাজ যা আপনি আজই পেতে পারেন, সবচেয়ে দ্রুত থেকে সবচেয়ে কঠিন ক্রমে। প্রতিটি ধাপ দেখতে একটি গাইড খুলুন।

সহজএকা~1 মিনিট

Quickdraw

একটি issue বা pull request খোলার 5 মিনিটের মধ্যে বন্ধ করুন।

ধাপগুলো দেখুন (4)

  1. আপনার কোনো সংগ্রহস্থলে একটি নতুন সমস্যা আছে (Issue) অথবা অনুরোধ টান (Pull Request) তৈরি করতে হবে।

  2. এখন আপনাকে একটি শিরোনাম লিখতে হবে এবং একটি মন্তব্য করতে হবে (যদি আপনি চান)। এবং তারপর, "Submit New issue" বোতামে ক্লিক করুন।

  3. আপনার ইচ্ছামত যেকোনো মন্তব্য করুন (আপনি একটি সমস্যা বন্ধ করতে পারেন বা মন্তব্য ছাড়াই অনুরোধ টানতে পারেন)। এবং তারপর "close issue/close pull request" এ ক্লিক করুন।

  4. সম্পন্ন, আপনি এখন আপনার কৃতিত্বের তালিকায় Quickdraw কৃতিত্ব দেখতে পাবেন।

সহজ2য় অ্যাকাউন্ট লাগবে

YOLO

রিভিউয়ার চাওয়া সত্ত্বেও রিভিউ ছাড়াই একটি pull request merge করুন।

ধাপগুলো দেখুন (9)

  1. প্রথমত, আপনাকে সংগ্রহস্থলটি খুলতে হবে এবং সেটিংসে যেতে হবে।

  2. দ্বিতীয়ত, আপনাকে সহকর্মী বিভাগে যেতে হবে এবং এই বিভাগে, আপনার সংগ্রহস্থলে অ্যাক্সেস আছে এমন একটি অ্যাকাউন্টকে আমন্ত্রণ জানান।

  3. তৃতীয়ত, আপনাকে আপনার সংগ্রহস্থলে একটি নতুন শাখা যোগ করতে হবে।

  4. এখন, আপনাকে সেই নতুন শাখায় একটি ফাইল যুক্ত করতে হবে।

  5. ফাইল যোগ করুন এবং এটির জন্য বিশদ বিবরণ দিন এবং অবশেষে আপনার পরিবর্তনগুলি করুন

  6. সবুজ বোতামে ক্লিক করুন, রিভিউ এবং অনুরোধ টানুন।

  7. ধাপ 2-এ একজন পর্যালোচক হিসেবে আমন্ত্রিত ব্যক্তিকে যোগ করুন এবং একটি পুল অনুরোধ তৈরি করুন।

  8. অবশেষে, আপনার পর্যালোচক চেক করুন এবং তারপর "Merge pull request" এ ক্লিক করুন।

  9. সম্পন্ন, আপনি এখন আপনার কৃতিত্বের তালিকায় Yolo অর্জন দেখতে পাবেন।

মাঝারিmerge লাগবে

Pull Shark

2টি pull request merge করান।

16, 128 এবং 1024টি merge হওয়া pull request-এ উচ্চতর স্তর।

ধাপগুলো দেখুন (5)

  1. আপনাকে যেকোন রিপোজিটরি থেকে ফর্ক করতে হবে (আপনি যেকোনো রিপোজিটরি কাঁটাচামচ করতে পারেন)।

  2. যখন আপনার "forked" রিপোজিটরি তৈরি করা হয়, তখন আপনাকে "forked" রিপোজিটরিতে কিছু পরিবর্তন করতে হবে (একটি নতুন ফাইল যোগ করা বা কোডে কিছু পরিবর্তন করার মতো যেকোনো কিছু)। এর পরে, আপনাকে "pull request" ট্যাবে যেতে হবে;

  3. create pull request বোতামে ক্লিক করুন;

  4. এখন আপনি "merge" করতে পারেন সবুজ টেক্সট প্রদর্শিত হবে, যার মানে আপনি আপনার "pull request" মার্জ করতে পারেন, তাই সফলভাবে আপনার "pull request" তৈরি করতে "Create Pull request" বোতামে ক্লিক করুন। তারপরে আপনার রিপোজিটরির স্রষ্টার দ্বারা আপনার অনুরোধটি প্রক্রিয়া করার জন্য আপনাকে অপেক্ষা করতে হবে।

    পুল শার্ক কৃতিত্ব পেতে আপনার 2টি মার্জ সহ একটি "pull request" প্রয়োজন৷

  5. সম্পন্ন, আপনি এখন আপনার কৃতিত্বের তালিকায় পুল শার্ক অ্যাচিভমেন্ট দেখতে পাবেন।

মাঝারিসহ-লেখক লাগবে

Pair Extraordinaire

এমন একটি pull request-এ commit-এর সহ-লেখক হন যা merge হয়। আপনি এবং আপনার সহ-লেখক দুজনেই এটি পাবেন।

10, 24 এবং 48টি সহ-লেখক হিসেবে merge হওয়া pull request-এ উচ্চতর স্তর।

ধাপগুলো দেখুন (6)

  1. GitHub Desktop আপনার অভ্যন্তরীণ সংগ্রহস্থল ফাইল থেকে আপনার সংগ্রহস্থল যোগ করার জন্য ইনস্টল করা হয়.

  2. একটি স্থানীয় সংগ্রহস্থল যোগ করুন এবং প্রতিশ্রুতিবদ্ধ করুন এবং আপনার পরিবর্তিত ফাইলগুলি পুশ করুন।

  3. ফিল্টার বক্স ব্যবহার করার দরকার নেই, শুধু "New Branch" ক্লিক করুন এবং আপনার সংগ্রহস্থলের জন্য একটি নতুন শাখা তৈরি করুন।

  4. আপনার শিরোনাম বাক্সে একটি সারসংক্ষেপ যোগ করুন, তারপর একটি বিবরণ যোগ করুন, অবশেষে একটি GitHub ব্যবহারকারীর দ্বারা সহ-লেখকত্ব যোগ করুন (আপনাকে যা করতে হবে তা হল আপনার সংগ্রহস্থলে একটি ফাইল কমিট করা (ফাইলগুলিকে ধাক্কা দেবেন না))।

    কমান্ড লাইন পছন্দ করেন? তাহলে আপনার commit মেসেজের শেষে এই লাইনটি যোগ করুন:Co-authored-by: Their Name <their-email@example.com>

  5. এখন GitHub-এ আপনার সংগ্রহস্থলটি পরীক্ষা করে দেখুন এবং "Assignees" যোগ করুন, এবং তারপর "মার্জ পুল রিকোয়েস্ট" বোতামে ক্লিক করুন (Pair Extraordinaire উভয় অ্যাকাউন্টই পাবেন (আপনি এবং সহ-লেখক))।

  6. সম্পন্ন, আপনি এখন আপনার কৃতিত্বের তালিকায় পেয়ার এক্সট্রা-ডিনিয়র অর্জন দেখতে পাবেন।

কঠিনঅন্যদের লাগবে

Starstruck

এমন একটি রিপোজিটরির মালিক হন যা 16টি স্টার পায়। পরে রিপোজিটরি ট্রান্সফার করলেও এটি গণনা হয়।

128, 512 এবং 4096টি স্টারে উচ্চতর স্তর।

ধাপগুলো দেখুন (2)

  1. আপনার ব্যবহারকারীর নামে নিবন্ধিত প্রতিটি প্রকল্পের জন্য আপনার শুধুমাত্র 16 স্টার প্রয়োজন। আপনার সংস্থা বা সংগ্রহস্থলের অন্যান্য ব্যবহারকারীদের কাছ থেকে গ্রহণ করুন।

  2. সম্পন্ন, আপনি এখন আপনার কৃতিত্বের তালিকায় Starstruck কৃতিত্ব দেখতে পাবেন।

কঠিনঅন্যদের লাগবে

Galaxy Brain

একটি পাবলিক রিপোজিটরির Discussions-এ আপনার 2টি উত্তর গৃহীত করান।

8, 16 এবং 32টি গৃহীত উত্তরে উচ্চতর স্তর।

ধাপগুলো দেখুন (5)

  1. যেকোনো পাবলিক রিপোজিটরির Discussions ট্যাবে যান এবং Q&A বিভাগ (অথবা অন্য যেকোনো বিভাগ যেখানে উত্তর চিহ্নিত করা যায়) নির্বাচন করুন। GitHub-এর নিজস্ব Community ফোরামে দেওয়া উত্তর আর গণনা করা হয় না, কারণ GitHub সেখানে অর্জন বন্ধ করে দিয়েছে।

    খেয়াল রাখুন: GitHub-এর নিজস্ব Community ফোরামের উত্তর আর গণনা হয় না। GitHub সেখানে অ্যাচিভমেন্ট বন্ধ করে দিয়েছে।

  2. এখন আপনি আপনার পছন্দ অনুযায়ী অনুত্তরিত প্রশ্ন অনুসন্ধান করতে পারেন। এবং উত্তর দিতে প্রশ্ন.

  3. প্রশ্নের সঠিক উত্তরটি লিখুন (প্রশ্ন ডিজাইনার দ্বারা উপস্থাপিত উত্তর হিসাবে বেছে নেওয়ার জন্য আপনার উত্তরটি অবশ্যই সেরা উত্তর হতে হবে)।

  4. গ্যালাক্সি ব্রেইন অর্জনের জন্য আপনার দুটি উপস্থাপিত উত্তর প্রয়োজন।

  5. সম্পন্ন, আপনি এখন আপনার কৃতিত্বের তালিকায় Galaxy Brain কৃতিত্ব দেখতে পাবেন।

সহজটাকা লাগে

Public Sponsor

GitHub Sponsors-এর মাধ্যমে একজন ওপেন-সোর্স ডেভেলপারকে স্পনসর করুন।

ধাপগুলো দেখুন (5)

  1. (প্রথমে আপনাকে জানতে হবে, এই ব্যাজটি পেতে আপনার একটি ক্রেডিট কার্ড থাকতে হবে এবং কিছু অর্থ দান করতে হবে)। তারপর আপনাকে প্রথমে GitHub সমর্থক পৃষ্ঠা খুলতে হবে, এবং তারপর "See your top dependencies" বোতামে ক্লিক করুন৷

  2. এখানে আপনি ডেভেলপারদের একটি তালিকা দেখতে পাবেন যাদেরকে আপনি অর্থ দান করতে পারেন (যেসব GitHub ব্যবহারকারীদের জন্য আপনি অর্থ দান করতে পারেন তাদের জন্য স্পনসর বোতাম দিয়ে)।

  3. একবার আপনি একজন স্পনসর খুঁজে পেলে, আপনি মাসে কতটা দান করতে চান তা চয়ন করার জন্য আপনি একটি পৃষ্ঠা দেখতে পাবেন।

  4. এখানে একটি অর্থপ্রদানের জন্য একটি ফর্ম রয়েছে, যখন আপনার অর্থপ্রদান শেষ হবে, আপনি আপনার প্রোফাইলে আপনার ব্যাজগুলি দেখতে পাবেন (বিটা সংস্করণে এখন 30টি দেশের জন্য অর্থপ্রদানের পদ্ধতি রয়েছে)৷

  5. সম্পন্ন, আপনি এখন আপনার কৃতিত্বের তালিকায় সর্বজনীন স্পনসরের কৃতিত্ব দেখতে পাবেন।
