Miễn phí, từng bước, có ảnh chụp màn hình

Mở khóa thành tựu GitHub của bạn.

Thành tựu là những huy hiệu GitHub gắn lên hồ sơ của bạn khi bạn làm một số việc nhất định, như merge pull request hay trả lời câu hỏi. Trang này chỉ cho bạn chính xác cách nhận từng cái.

Thành tựu có thể nhận

Bảy huy hiệu bạn có thể nhận ngay hôm nay, xếp từ nhanh nhất đến khó nhất. Mở một hướng dẫn để xem từng bước.

DễTự làm~1 phút

Quickdraw

Đóng một issue hoặc pull request trong vòng 5 phút sau khi mở.

Xem các bước (4)

  1. Bạn cần tạo Issue mới hoặc Pull Request trong bất kỳ repo nào bạn muốn.

  2. Bây giờ bạn nên viết tiêu đề và để lại bình luận (nếu muốn). Sau đó, nhấp vào nút Submit new issue.

  3. Viết bất kỳ nhận xét nào bạn muốn. Sau đó nhấp vào Close issue/close pull request.

  4. Xong, bây giờ bạn có thể thấy Thành tựu Quickdraw trong danh sách của mình.

DễCần tài khoản thứ 2

YOLO

Merge một pull request mà không cần review, dù đã yêu cầu người review.

Xem các bước (9)

  1. Đầu tiên, mở repo và vào settings.

  2. Thứ hai, bạn cần vào danh mục contributor và trong phần này, hãy mời một tài khoản mà bạn có quyền truy cập vào repo.

  3. Thứ ba, bạn cần thêm một branch mới vào repo của mình.

  4. Bây giờ, bạn cần thêm tệp vào branch mới mà bạn đã tạo.

  5. Thêm tệp và mô tả, cuối cùng commit các thay đổi của bạn

  6. Bấm vào nút màu xanh lá cây, compare and pull request.

  7. Thêm người được mời ở bước 2 làm Reviewer và tạo pull request.

  8. Cuối cùng, hãy kiểm tra xem Reviewer của bạn có chưa và sau đó nhấp vào merge pull request.

  9. Xong, bây giờ bạn có thể thấy Thành tựu Yolo đó trong danh sách của mình.

Trung bìnhCần merge

Pull Shark

Có 2 pull request được merge.

Cấp cao hơn ở mốc 16, 128 và 1024 pull request được merge.

Xem các bước (5)

  1. Bạn cần fork từ một repo bất kỳ nào bạn muốn.

  2. Khi fork repo được tạo, bạn cần thay đổi một số thứ và sau đó commit để tạo pull request vào repo chính.

  3. Nhấn Create pull request.

  4. Bây giờ bạn có thể thấy dòng màu xanh Able to merge, điều đó có nghĩa là bạn có thể merge pull request của mình. Hãy nhấp vào nút Create pull request. Sau đó, bạn phải đợi request của mình được chủ repo merge.

    Bạn cần merge 2 pull request để nhận Pull Shark Achievement

  5. Xong, bây giờ bạn có thể thấy Thành tựu Pull Shark trong danh sách của mình.

Trung bìnhCần đồng tác giả

Pair Extraordinaire

Đồng tác giả một commit trong pull request được merge. Cả bạn và đồng tác giả đều nhận được.

Cấp cao hơn ở mốc 10, 24 và 48 pull request đồng tác giả được merge.

Xem các bước (6)

  1. Bạn cần cài đặt GitHub Desktop. Bạn cần thêm repo của mình từ local.

  2. Thêm một local repository.

  3. Nhấn vào New branch để tạo branch mới cho repo của bạn.

  4. Thêm tiêu đề cho commit, sau đó là mô tả. Cuối cùng thêm Co-Author bằng Username GitHub (người đó đã được tham gia vào repo nếu như đây là private repo). Commit và tạo pull request.

    Thích dùng dòng lệnh? Thay vào đó, hãy thêm dòng này vào cuối commit message:Co-authored-by: Tên Họ <their-email@example.com>

  5. Kiểm tra repo trên GitHub và thêm Assignees, nhấn Merge pull request (Thành tựu Pair Extraordinaire sẽ được trao cho cả hai).

  6. Xong, bây giờ bạn có thể thấy Thành tựu Pair Extraordinaire trong danh sách của mình.

KhóCần người khác

Starstruck

Sở hữu một repository đạt 16 sao. Vẫn được tính nếu sau này bạn chuyển repository đi.

Cấp cao hơn ở mốc 128, 512 và 4096 sao.

Xem các bước (2)

  1. Bạn chỉ cần 16 sao cho mỗi repo được đăng ký tên người dùng của bạn. Nhận từ những người dùng khác trong tổ chức hoặc repo của bạn.

  2. Xong, bây giờ bạn có thể thấy Thành tựu Starstruck trong danh sách của mình.

KhóCần người khác

Galaxy Brain

Có 2 câu trả lời được chấp nhận trong Discussions của một repository công khai.

Cấp cao hơn ở mốc 8, 16 và 32 câu trả lời được chấp nhận.

Xem các bước (5)

  1. Mở tab Discussions của bất kỳ repository công khai nào và chọn danh mục Q&A (hoặc bất kỳ danh mục nào khác cho phép đánh dấu câu trả lời). Câu trả lời trên diễn đàn GitHub Community chính thức không còn được tính nữa, vì GitHub đã tắt thành tựu ở đó.

    Lưu ý: câu trả lời trên diễn đàn Community của chính GitHub không còn được tính. GitHub đã tắt thành tựu ở đó.

  2. Tìm hiểu và trả lời câu hỏi trong bất kỳ danh mục nào mà bạn muốn.

  3. Hãy soạn câu trả lời thật chuẩn xác và hoàn chỉnh, nó cần được người hỏi chấp nhận.

  4. Bạn cần hoàn thành ít nhất 2 câu hỏi để nhận Thành tựu Galaxy Brain.

  5. Xong, bây giờ bạn có thể thấy Thành tựu Galaxy Brain trong danh sách của mình.

DễTốn tiền

Public Sponsor

Tài trợ cho một lập trình viên mã nguồn mở qua GitHub Sponsors.

Xem các bước (5)

  1. (Đầu tiên bạn cần biết, để có được huy hiệu này, bạn cần có thẻ tín dụng và quyên góp một số tiền). Sau đó, trước tiên bạn cần mở trang GitHub Sponsors, sau đó nhấp vào nút See your top dependencies.

  2. Bạn có thể xem danh sách các developer mà bạn có thể quyên góp cho họ tại đây. (Bạn có thể được tài trợ cho bất kỳ người dùng GitHub nào có nút tài trợ trên trang của họ).

  3. Sau khi bạn tìm thấy một người để được tài trợ. bạn có thể xem một trang để chọn số tiền bạn muốn quyên góp mỗi tháng.

  4. Một form thanh toán sẽ hiện ra. Sau khi thanh toán của bạn kết thúc, bạn có thể thấy huy hiệu trong hồ sơ của mình (30 quốc gia có phương thức thanh toán ở phiên bản Beta).

  5. Xong, bây giờ bạn có thể thấy Thành tựu Public Sponsor trong danh sách của mình.

Màu da 👋🏽

Một số huy hiệu, như Quickdraw và Starstruck, theo màu da emoji của bạn. Đổi nó trong cài đặt giao diện.

Ẩn đi nếu bạn muốn

Không thích huy hiệu? Bạn có thể tắt thành tựu trên hồ sơ trong cài đặt hồ sơ.

Để xem quy định chính thức, hãy đọc tài liệu GitHub về hiển thị huy hiệu trên hồ sơ.

Chơi đẹp 🏁

Hướng dẫn này giúp bạn hiểu cách thành tựu hoạt động. Hãy tôn trọng Điều khoản dịch vụ của GitHub và quy tắc cộng đồng: đừng spam dự án khác chỉ để gom huy hiệu. Cách tốt nhất để nhận chúng là tham gia dự án thật và giúp đỡ người khác.
