Gratis, paso a paso y con capturas

Desbloquea tus logros de GitHub.

Los logros son las insignias que GitHub pone en tu perfil cuando haces ciertas cosas, como fusionar pull requests o responder preguntas. Este sitio te muestra exactamente cómo conseguir cada uno.

Logros que puedes conseguir

Siete insignias que puedes conseguir hoy, ordenadas de la más rápida a la más difícil. Abre una guía para ver cada paso.

FácilEn solitario~1 minuto

Quickdraw

Cierra un issue o pull request en los 5 minutos siguientes a abrirlo.

Ver los pasos (4)

  1. Necesitas crear un nuevo problema (issue) o solicitud de extracción (pull request) en cualquier repositorio que desees.

  2. Ahora debes escribir un título y dejar un comentario (si lo deseas). Luego, haz clic en el botón "Submit new issue" (Enviar nuevo problema).

  3. Escribe cualquier comentario que desees (también puedes cerrar el problema o la solicitud de extracción sin comentar). Luego, haz clic en "Close issue" o "Close pull request" (Cerrar problema/cerrar solicitud de extracción).

  4. ¡Listo! Ahora puedes ver el logro de Quickdraw en tu lista de logros.

FácilRequiere una 2.ª cuenta

YOLO

Fusiona un pull request sin revisión, aunque se haya pedido un revisor.

Ver los pasos (9)

  1. Primero, necesitas abrir el repositorio y dirigirte a la configuración (settings).

  2. Segundo, debes ir a la categoría de colaboradores (collaborators) y en esta sección, invitar a una cuenta a la que tengas acceso al repositorio.

  3. Tercero, necesitas agregar una nueva rama a tu repositorio.

  4. Ahora, debes agregar un archivo a la nueva rama que creaste.

  5. Agrega el archivo y haz commit de la descripción para él, y finalmente realiza un commit de tus cambios.

  6. Haz clic en el botón verde, "compare and pull request" (comparar y solicitud de extracción).

  7. Agrega a la persona invitada en el paso 2 como revisor (Reviewer), y crea la solicitud de extracción (pull request).

  8. Por último, verifica que tu revisor y luego haz clic en "Merge pull request" (fusionar solicitud de extracción).

  9. ¡Listo! Ahora puedes ver el logro Yolo en tu lista de logros.

MediaRequiere un merge

Pull Shark

Consigue que te fusionen 2 pull requests.

Niveles superiores con 16, 128 y 1024 pull requests fusionados.

Ver los pasos (5)

  1. Necesitas obtener un fork de un repositorio (puedes hacer fork de cualquier repositorio que desees).

  2. Cuando se crea tu repositorio bifurcado, necesitas hacer algunos cambios en él (cualquier cambio como agregar un nuevo archivo o hacer modificaciones en el código). Después de eso, debes ir a la pestaña de solicitudes de extracción (pull request);

  3. Haz clic en el botón "Create pull request" (Crear solicitud de extracción);

  4. Ahora podrás ver un texto verde que indica que puedes fusionar tu solicitud de extracción. Así que haz clic en el botón "Create Pull request" para crear tu solicitud de extracción exitosamente. Luego tendrás que esperar a que el creador del repositorio acepte tu solicitud.

    Necesitas 2 solicitudes de extracción fusionadas para obtener el logro de Pull Shark.

  5. ¡Listo! Ahora puedes ver el logro de Pull Shark en tu lista de logros.

MediaRequiere un coautor

Pair Extraordinaire

Sé coautor de un commit en un pull request que se fusione. Tú y tu coautor lo conseguís.

Niveles superiores con 10, 24 y 48 pull requests fusionados en coautoría.

Ver los pasos (6)

  1. Necesitas instalar GitHub Desktop, y luego agregar tu repositorio desde tu archivo de repositorio interno.

  2. Agrega un repositorio local y realiza un commit y un push de los archivos modificados.

  3. No es necesario usar el cuadro de filtro, simplemente haz clic en "New branch" y crea una nueva rama para tu repositorio.

  4. Agrega un resumen en el cuadro de título, luego agrega una descripción. Por último, agrega un coautor mediante el nombre de usuario de GitHub (solo necesitas hacer commit de un archivo en tu repositorio, no hagas push de los archivos).

    ¿Prefieres la línea de comandos? Añade esta línea al final del mensaje de tu commit:Co-authored-by: Su Nombre <their-email@example.com>

  5. Ahora verifica tu repositorio en GitHub, agrega asignados y luego haz clic en el botón "Merge pull request" (el logro Pair Extraordinaire se otorgará a ambas cuentas, la tuya y la del coautor).

  6. ¡Listo! Ahora puedes ver el logro Pair Extraordinaire en tu lista de logros.

DifícilRequiere otras personas

Starstruck

Ten un repositorio que llegue a 16 estrellas. Sigue contando si luego transfieres el repositorio.

Niveles superiores con 128, 512 y 4096 estrellas.

Ver los pasos (2)

  1. Solo necesitas 16 estrellas para cada proyecto registrado en tu nombre de usuario. Puedes recibirlas de otros usuarios en tu organización o repositorio.

  2. ¡Listo! Ahora puedes ver el logro de Starstruck en tu lista de logros.

DifícilRequiere otras personas

Galaxy Brain

Consigue que acepten 2 de tus respuestas en las Discussions de un repositorio público.

Niveles superiores con 8, 16 y 32 respuestas aceptadas.

Ver los pasos (5)

  1. Abre la pestaña Discussions de cualquier repositorio público y elige la categoría Q&A (o cualquier otra categoría en la que se pueda marcar una respuesta). Las respuestas en el foro oficial GitHub Community ya no cuentan, porque GitHub desactivó los logros allí.

    Ojo: las respuestas en el foro Community de GitHub ya no cuentan. GitHub desactivó los logros allí.

  2. Ahora debes encontrar preguntas sin respuesta en las categorías que desees y responder a las preguntas.

  3. Escribe una respuesta correcta a la pregunta (Tu respuesta debe ser la mejor posible para ser seleccionada como la respuesta enviada por el diseñador de la pregunta).

  4. Necesitas tener dos respuestas enviadas en las categorías que desees para obtener el logro de Galaxy Brain.

  5. ¡Listo! Ahora puedes ver el logro de Galaxy Brain en tu lista de logros.

FácilCuesta dinero

Public Sponsor

Patrocina a un desarrollador de código abierto a través de GitHub Sponsors.

Ver los pasos (5)

  1. (Primero debes saber que para obtener esta insignia necesitas una tarjeta de crédito y donar dinero). Luego, necesitas abrir la página de GitHub Sponsors primero y luego hacer clic en el botón "See your top dependencies" (Ver tus dependencias principales).

  2. Verás una lista de desarrolladores a los que puedes donar aquí. (Puedes patrocinar a cualquier usuario de GitHub que tenga el botón de patrocinio en sus páginas).

  3. Después de encontrar a la persona a la que deseas patrocinar, verás una página para seleccionar cuánto deseas donar por mes.

  4. Aquí hay un formulario de pago; después de finalizar tu pago, podrás ver tu insignia en tu perfil (en la versión Beta, 30 países tienen métodos de pago disponibles por ahora).

  5. ¡Listo! Ahora puedes ver el logro de Public Sponsor en tu lista de logros.

Tonos de piel 👋🏽

Algunas insignias, como Quickdraw y Starstruck, siguen el tono de piel de tus emoji. Cámbialo en tu configuración de apariencia.

Ocúltalas si quieres

¿No te van las insignias? Puedes desactivar los logros de tu perfil en la configuración del perfil.

Para las reglas oficiales, consulta la documentación de GitHub sobre mostrar insignias en tu perfil.

Juega limpio 🏁

Esta guía existe para enseñarte cómo funcionan los logros. Respeta los Términos de servicio y las normas de la comunidad de GitHub: no hagas spam en otros proyectos solo para coleccionar insignias. La mejor forma de conseguirlas es participar en proyectos reales y ayudar a otras personas.
