Buka achievement GitHub kamu.

Achievement yang bisa didapat

Tujuh lencana yang bisa kamu dapatkan hari ini, diurutkan dari yang tercepat sampai tersulit. Buka panduan untuk melihat semua langkahnya.

MudahSendiri~1 menit

Quickdraw

Tutup issue atau pull request dalam 5 menit setelah dibuka.

Lihat langkah (4)

  1. Anda perlu membuat Issue atau Pull Request Baru di repositori mana pun yang Anda inginkan.

  2. Sekarang Anda harus menulis judul dan meninggalkan komentar (jika Anda mau). Kemudian klik tombol Submit new issue.

  3. Tulis komentar apa pun yang Anda inginkan (Anda dapat menutup issue atau pull request tanpa memberi komentar juga). Kemudian klik Close issue / close pull request.

  4. Selesai, sekarang Anda dapat melihat Prestasi Quickdraw di daftar prestasi Anda.

MudahPerlu akun ke-2

YOLO

Merge pull request tanpa review, padahal reviewer sudah diminta.

Lihat langkah (9)

  1. Pertama, Anda perlu membuka repositori dan pergi ke pengaturan.

  2. Kedua, Anda perlu pergi ke kategori kolaborator dan dalam bagian ini, undang akun yang memiliki akses ke repositori.

  3. Ketiga, Anda perlu menambahkan cabang baru ke repositori Anda.

  4. Sekarang, Anda perlu menambahkan file ke cabang baru yang Anda buat.

  5. Tambahkan file dan lakukan deskripsi untuk itu, dan akhirnya lakukan commit perubahan Anda.

  6. Klik tombol hijau, compare, dan pull request.

  7. Tambahkan orang yang diundang pada langkah-2 sebagai Reviewer, dan buat pull request.

  8. Terakhir, Periksa bahwa Reviewer Anda dan Klik pada Merge pull request.

  9. Selesai, sekarang Anda dapat melihat Prestasi Yolo di daftar prestasi Anda.

SedangPerlu merge

Pull Shark

Dapatkan 2 pull request yang di-merge.

Tingkat lebih tinggi di 16, 128, dan 1024 pull request yang di-merge.

Lihat langkah (5)

  1. Anda perlu fork dari sebuah repositori (Anda dapat fork dari repositori apa pun yang Anda inginkan).

  2. Setelah repositori yang Anda fork dibuat, Anda perlu melakukan beberapa perubahan di repositori yang telah di-fork (perubahan apa pun seperti menambahkan file baru atau melakukan beberapa perubahan pada kode!). Setelah itu, pergilah ke tab pull request.

  3. Klik tombol create pull request;

  4. Sekarang Anda dapat melihat teks hijau yang menunjukkan Anda dapat menggabungkan permintaan pull Anda, Jadi klik tombol Create Pull request untuk membuat permintaan pull Anda berhasil. Kemudian Anda harus menunggu permintaan Anda untuk digabungkan oleh pembuat repositori.

    Anda membutuhkan 2 pull request yang digabungkan, untuk mendapatkan Prestasi Pull Shark

  5. Selesai, sekarang Anda dapat melihat Prestasi Pull Shark di daftar prestasi Anda.

SedangPerlu co-author

Pair Extraordinaire

Jadi co-author sebuah commit di pull request yang di-merge. Kamu dan co-author-mu sama-sama mendapatkannya.

Tingkat lebih tinggi di 10, 24, dan 48 pull request co-author yang di-merge.

Lihat langkah (6)

  1. Anda perlu menginstal GitHub Desktop, Anda perlu menambahkan repositori Anda dari file repositori internal Anda.

  2. Tambahkan repositori lokal & Commit dan push file yang telah diubah.

  3. Tidak perlu menggunakan kotak filter, cukup klik New branch dan Create new branch Untuk repositori Anda.

  4. Tambahkan ringkasan dalam kotak judul Anda, Kemudian tambahkan deskripsi, Terakhir tambahkan Co-Author By Username GitHub (Anda hanya perlu melakukan commit pada file di repositori Anda (Jangan Push File)).

    Lebih suka command line? Tambahkan baris ini di akhir pesan commit-mu:Co-authored-by: Nama Mereka <their-email@example.com>

  5. Sekarang periksa repositori Anda di GitHub dan tambahkan Assignees, Dan kemudian klik tombol Merge pull request (Pair Extraordinaire akan diberikan kepada kedua akun (Anda dan Co-Author)).

  6. Selesai, sekarang Anda dapat melihat Prestasi Pair Extraordinaire di daftar prestasi Anda.

SulitPerlu orang lain

Starstruck

Miliki repository yang mencapai 16 bintang. Tetap dihitung meski nanti repository-nya kamu transfer.

Tingkat lebih tinggi di 128, 512, dan 4096 bintang.

Lihat langkah (2)

  1. Anda hanya perlu 16 bintang untuk setiap proyek yang terdaftar di repository Anda. Terima dari pengguna lain di organisasi atau repositori Anda.

  2. Selesai, sekarang Anda dapat melihat Prestasi Starstruck di daftar prestasi Anda.

SulitPerlu orang lain

Galaxy Brain

Dapatkan 2 jawabanmu diterima di Discussions sebuah repository publik.

Tingkat lebih tinggi di 8, 16, dan 32 jawaban diterima.

Lihat langkah (5)

  1. Buka tab Discussions di repositori publik mana pun dan pilih kategori Q&A (atau kategori lain yang memungkinkan jawaban ditandai). Jawaban di forum resmi GitHub Community tidak lagi dihitung, karena GitHub telah menonaktifkan prestasi di sana.

    Perhatian: jawaban di forum Community milik GitHub sendiri tidak dihitung lagi. GitHub sudah mematikan achievement di sana.

  2. Sekarang Anda perlu mencari Pertanyaan yang Belum Dijawab di kategori apa pun yang Anda inginkan. dan jawablah pertanyaan tersebut.

  3. Tulis jawaban yang benar untuk pertanyaan (Jawaban Anda harus menjadi jawaban terbaik yang mungkin untuk dipilih sebagai jawaban yang diajukan oleh desainer pertanyaan).

  4. Anda membutuhkan dua jawaban yang diajukan di kategori apa pun yang Anda inginkan untuk mendapatkan prestasi Galaxy Brain

  5. Selesai, sekarang Anda dapat melihat Prestasi Galaxy Brain di daftar prestasi Anda.

MudahBerbayar

Public Sponsor

Sponsori developer open source lewat GitHub Sponsors.

Lihat langkah (5)

  1. (Pertama, Anda perlu tahu, untuk mendapatkan lencana ini, Anda memerlukan kartu kredit dan menyumbangkan sejumlah uang). Kemudian Anda perlu membuka halaman GitHub Sponsors terlebih dahulu, dan kemudian klik tombol Lihat dependensi teratas Anda.

  2. Anda dapat melihat daftar pengembang yang dapat Anda sumbangi di sini. (Anda dapat menjadi sponsor pengguna GitHub mana pun yang memiliki tombol sponsor di halaman mereka.)

  3. Setelah Anda menemukan orang yang akan Anda sponsori. Anda dapat melihat halaman untuk memilih berapa banyak yang ingin Anda sumbangkan setiap bulan.

  4. Ada formulir pembayaran di sini, setelah pembayaran Anda selesai. Anda dapat melihat lencana Anda di profil Anda (di versi Beta, 30 negara memiliki metode pembayaran untuk saat ini).

  5. Selesai, sekarang Anda dapat melihat Prestasi Public Sponsor di daftar prestasi Anda.

Main yang adil 🏁

Panduan ini dibuat untuk mengajarkan cara kerja achievement. Hormati Ketentuan Layanan dan pedoman komunitas GitHub: jangan spam proyek lain hanya demi mengoleksi lencana. Cara terbaik mendapatkannya adalah ikut proyek sungguhan dan membantu orang lain.
