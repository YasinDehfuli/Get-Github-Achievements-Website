Osiągnięcia do zdobycia

Siedem odznak, które możesz zdobyć już dziś, od najszybszej do najtrudniejszej. Otwórz poradnik, by zobaczyć każdy krok.

ŁatweSamodzielnie~1 minuta

Quickdraw

Zamknij issue lub pull request w ciągu 5 minut od otwarcia.

Pokaż kroki (4)

  1. Utwórz nowe zgłoszenie (issue) lub pull request w wybranym repozytorium.

  2. Wpisz tytuł i, jeśli chcesz, dodaj komentarz. Następnie kliknij przycisk Submit new issue.

  3. Dodaj dowolny komentarz, a następnie kliknij Close issue lub Close pull request. Możesz też zamknąć zgłoszenie albo pull request bez komentowania.

  4. Gotowe. Osiągnięcie Quickdraw powinno pojawić się na liście Twoich osiągnięć.

ŁatweWymaga 2. konta

YOLO

Zmerguj pull request bez review, mimo że poproszono o recenzenta.

Pokaż kroki (9)

  1. Otwórz repozytorium i przejdź do ustawień.

  2. Przejdź do sekcji Collaborators i zaproś konto, które ma dostęp do repozytorium.

  3. Utwórz nową gałąź w repozytorium.

  4. Dodaj plik do utworzonej gałęzi.

  5. Dodaj plik, wpisz opis commita, a na koniec zatwierdź zmiany.

  6. Kliknij zielony przycisk Compare and pull request.

  7. Dodaj jako recenzenta osobę zaproszoną w kroku 2 i utwórz pull request.

  8. Sprawdź, czy recenzent jest przypisany, a następnie kliknij Merge pull request.

  9. Gotowe. Osiągnięcie YOLO powinno pojawić się na liście Twoich osiągnięć.

ŚrednieWymaga merge

Pull Shark

Doprowadź do zmergowania 2 pull requestów.

Wyższe poziomy przy 16, 128 i 1024 zmergowanych pull requestach.

Pokaż kroki (5)

  1. Utwórz fork wybranego repozytorium.

  2. Wprowadź zmiany w swoim forku, na przykład dodaj plik lub zmodyfikuj kod. Następnie przejdź do zakładki pull requestów.

  3. Kliknij przycisk tworzenia pull requesta.

  4. Jeśli widzisz zielony komunikat informujący, że zmiany można scalić, kliknij Create pull request. Poczekaj, aż właściciel repozytorium scali Twoje zgłoszenie.

    Do zdobycia osiągnięcia Pull Shark potrzebujesz dwóch scalonych pull requestów.

  5. Gotowe. Osiągnięcie Pull Shark powinno pojawić się na liście Twoich osiągnięć.

ŚrednieWymaga współautora

Pair Extraordinaire

Bądź współautorem commita w pull requeście, który zostanie zmergowany. Odznakę dostajesz Ty i Twój współautor.

Wyższe poziomy przy 10, 24 i 48 zmergowanych pull requestach ze współautorstwem.

Pokaż kroki (6)

  1. Zainstaluj GitHub Desktop i dodaj repozytorium ze swoich lokalnych plików.

  2. Dodaj lokalne repozytorium, a następnie zatwierdź i wypchnij zmienione pliki.

  3. Nie musisz używać pola filtrowania. Kliknij New branch i utwórz nową gałąź dla repozytorium.

  4. Wpisz tytuł i opis, a na końcu dodaj współautora, podając jego nazwę użytkownika GitHub. Wystarczy zatwierdzić plik w repozytorium — nie wypychaj plików.

    Wolisz wiersz poleceń? Zamiast tego dodaj tę linię na końcu opisu commita:Co-authored-by: Imię Nazwisko <their-email@example.com>

  5. Otwórz repozytorium na GitHubie i dodaj osoby przypisane do zgłoszenia (assignees). Następnie kliknij Merge pull request. Odznakę Pair Extraordinaire otrzymają oba konta: Twoje i współautora.

  6. Gotowe. Osiągnięcie Pair Extraordinaire powinno pojawić się na liście Twoich osiągnięć.

TrudneWymaga innych osób

Starstruck

Miej repozytorium, które zdobędzie 16 gwiazdek. Liczy się nawet wtedy, gdy później je przeniesiesz.

Wyższe poziomy przy 128, 512 i 4096 gwiazdkach.

Pokaż kroki (2)

  1. Repozytorium przypisane do Twojego konta musi otrzymać 16 gwiazdek od innych użytkowników. Mogą to być użytkownicy Twojej organizacji lub repozytorium.

  2. Gotowe. Osiągnięcie Starstruck powinno pojawić się na liście Twoich osiągnięć.

TrudneWymaga innych osób

Galaxy Brain

Zdobądź 2 zaakceptowane odpowiedzi w Discussions publicznego repozytorium.

Wyższe poziomy przy 8, 16 i 32 zaakceptowanych odpowiedziach.

Pokaż kroki (5)

  1. Otwórz zakładkę Discussions dowolnego publicznego repozytorium i wybierz kategorię Q&A (lub inną kategorię, w której można oznaczyć odpowiedź). Odpowiedzi na oficjalnym forum GitHub Community już się nie liczą, ponieważ GitHub wyłączył tam osiągnięcia.

    Uwaga: odpowiedzi na forum Community samego GitHuba już się nie liczą. GitHub wyłączył tam osiągnięcia.

  2. Znajdź pytania bez odpowiedzi w wybranej kategorii i odpowiedz na nie.

  3. Udziel poprawnej odpowiedzi. Powinna być możliwie najlepsza, aby autor pytania wybrał ją jako zaakceptowaną.

  4. Aby zdobyć Galaxy Brain, potrzebujesz dwóch zaakceptowanych odpowiedzi w dowolnych kategoriach.

  5. Gotowe. Osiągnięcie Galaxy Brain powinno pojawić się na liście Twoich osiągnięć.

ŁatweKosztuje

Public Sponsor

Wesprzyj twórcę open source przez GitHub Sponsors.

Pokaż kroki (5)

  1. Do zdobycia tej odznaki potrzebna jest karta płatnicza i wpłata. Otwórz stronę GitHub Sponsors, a następnie kliknij See your top dependencies.

  2. Zobaczysz listę programistów, których możesz wesprzeć. Możesz sponsorować dowolnego użytkownika GitHub, który ma przycisk sponsorowania na swojej stronie.

  3. Wybierz osobę, którą chcesz sponsorować, a następnie określ miesięczną kwotę wpłaty.

  4. Wypełnij formularz płatności. Po jej zakończeniu odznaka powinna pojawić się na Twoim profilu. W wersji beta metody płatności były dostępne w 30 krajach.

  5. Gotowe. Osiągnięcie Public Sponsor powinno pojawić się na liście Twoich osiągnięć.

Graj fair 🏁

Ten poradnik ma pokazać, jak działają osiągnięcia. Szanuj Warunki korzystania z usługi GitHuba i zasady społeczności: nie spamuj innych projektów tylko po to, by zbierać odznaki. Najlepszy sposób, by je zdobyć, to udział w prawdziwych projektach i pomaganie innym.
