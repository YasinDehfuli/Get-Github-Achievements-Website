# Get GitHub Achievements — Website

**Live site:** https://yasindehfuli.github.io/Get-Github-Achievements-Website/

A simple, one-page website that teaches anyone how to earn GitHub achievement badges, step by step with screenshots. It's a friendly web version of the [4xmen/Get-Github-Achievements](https://github.com/4xmen/Get-Github-Achievements) guide.

## What's on the site

- **7 earnable achievements**: Quickdraw, YOLO, Pull Shark, Pair Extraordinaire, Starstruck, Galaxy Brain and Public Sponsor. Each has a difficulty tag, what you need, and a collapsible step-by-step guide with screenshots.
- **Progress tracker**: tick off the badges you've earned (saved in your browser).
- **More badges**: achievements still in testing, retired ones, and highlight badges.
- **19 languages**: English, Persian, Arabic, German, French, Russian, Turkish, Dutch, Chinese, Spanish, Indonesian, Hindi, Japanese, Armenian, Swahili, Portuguese, Bengali, Vietnamese and Polish (Persian and Arabic are right-to-left). Each language has its own page, e.g. [`/fa/`](https://yasindehfuli.github.io/Get-Github-Achievements-Website/fa/).

Direct links open a guide straight away, e.g. [`#yolo`](https://yasindehfuli.github.io/Get-Github-Achievements-Website/#yolo).

## How it's built

The pages are plain HTML generated by a small Python script (no dependencies):

```bash
python3 scripts/build.py
```

- `i18n/<lang>.json`: page text for each language (edit these to fix a translation)
- `data/guides/<lang>.json`: the step-by-step guides for each language
- `scripts/import_guides.py`: refreshes `data/guides/` from the original repository's translated guides (English is written by hand):

```bash
git clone --depth 1 https://github.com/4xmen/Get-Github-Achievements.git /tmp/gga
python3 scripts/import_guides.py /tmp/gga
python3 scripts/build.py
```

The build also writes `sitemap.xml` and `robots.txt` for search engines. Commit the generated files: GitHub Pages serves them as they are.

## Run it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Files

| File | Purpose |
| --- | --- |
| `index.html`, `<lang>/index.html` | Generated pages (don't edit by hand) |
| `style.css` | Styles (light and dark mode follow your system setting) |
| `main.js` | "Mark as earned" tracker, language menu, opening guides from links |
| `favicon.svg` | Trophy icon |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

Badge images and screenshots load directly from the [original repository](https://github.com/4xmen/Get-Github-Achievements/tree/main/assets), so updates there show up here automatically.
