Grátis, passo a passo, com capturas de tela

Desbloqueie suas conquistas do GitHub.

Conquistas são os emblemas que o GitHub fixa no seu perfil quando você faz certas coisas, como fazer merge de pull requests ou responder perguntas. Este site mostra exatamente como ganhar cada uma.

Conquistas disponíveis

Sete emblemas que você pode ganhar hoje, da mais rápida à mais difícil. Abra um guia para ver cada passo.

FácilSozinho~1 minuto

Quickdraw

Feche uma issue ou pull request em até 5 minutos após abri-la.

Mostrar os passos (4)

  1. Você precisa criar um novo "issue" ou "pull request" em qualquer repositório que desejar.

  2. Agora você deve escrever um título e deixar um comentário (se desejar). Em seguida, clique no botão “Submit new issue”.

  3. Escreva os comentários que desejar (você também pode encerrar o problema ou pull request sem comentar). Em seguida, clique em “Close with comment” ou “Fechar pull request”.

  4. Pronto! Agora você pode ver a conquista Quickdraw em sua lista de conquistas.

FácilPrecisa de uma 2ª conta

YOLO

Faça merge de um pull request sem revisão, mesmo tendo solicitado um revisor.

Mostrar os passos (9)

  1. Primeiro, você precisa abrir o repositório e acessar as configurações.

  2. Em segundo lugar, você deve ir até a categoria (collaborators) e nesta seção convidar uma conta à qual você tenha acesso ao repositório.

  3. Terceiro, você precisa adicionar um novo branch ao seu repositório.

  4. Agora, você precisa adicionar um arquivo ao novo branch que você criou.

  5. Adicione o arquivo e confirme a commit dele e, finalmente, confirme suas alterações.

  6. Clique no botão verde, "Compare & pull request".

  7. Adicione a pessoa convidada na etapa 2 como Revisor(Reviwer) e crie o pull request.

  8. Por fim, verifique seu revisor e clique em Merge pull request “Mesclar solicitação pull”.

  9. Pronto! Agora você pode ver a conquista do Yolo na sua lista de conquistas.

MédiaPrecisa de merge

Pull Shark

Tenha 2 pull requests com merge.

Níveis superiores com 16, 128 e 1024 pull requests com merge.

Mostrar os passos (5)

  1. Você precisa fazer Fork um repositório (você pode fazer Fork de qualquer repositório que desejar).

  2. Quando seu repositório em fork é criado, você precisa fazer algumas alterações nele (quaisquer alterações, como adicionar um novo arquivo ou fazer modificações no código). Depois disso, você precisa ir até a aba (pull requests);

  3. Clique no botão “New pull request”;

  4. Agora você verá um texto verde indicando que pode mesclar seu pull request. Portanto, clique no botão “Create pull request” para criar seu pull request com sucesso. Você terá então que esperar que o criador do repositório aceite sua solicitação.

    Você precisa de 2 pull requests mesclados/aceitos para obter a conquista Pull Shark.

  5. Pronto! Agora você pode ver a conquista Pull Shark em sua lista de conquistas.

MédiaPrecisa de coautor

Pair Extraordinaire

Seja coautor de um commit em um pull request que recebe merge. Você e seu coautor ganham a conquista.

Níveis superiores com 10, 24 e 48 pull requests com merge em coautoria.

Mostrar os passos (6)

  1. Você precisa instalar o GitHub Desktop e, em seguida, adicione seu repositório a partir do arquivo de repositório interno.

  2. Adicione um repositório local, confirme e envie os arquivos modificados.

  3. Não há necessidade de usar a caixa de filtro, basta clicar em “Nova branch” e criar uma branch nova para o seu repositório.

  4. Adicione um resumo na caixa de título e, em seguida, adicione uma descrição. Por fim, adicione um co-autor usando o nome de usuário do GitHub (você só precisa enviar um arquivo para o seu repositório, não faça push dos arquivos (não envie os arquivos para a branch).

    Prefere a linha de comando? Adicione esta linha ao final da mensagem do commit:Co-authored-by: Nome da Pessoa <their-email@example.com>

  5. Agora verifique seu repositório no GitHub, adicione cessionários (Assignees) e clique no botão “Merge pull request” (a conquista Pair Extraordinaire será concedida à sua conta e à do coautor).

  6. Preparar! Agora você pode ver a conquista Pair Extraordinaire em sua lista de conquistas.

DifícilPrecisa de outras pessoas

Starstruck

Tenha um repositório que chegue a 16 estrelas. Continua valendo mesmo se você transferir o repositório depois.

Níveis superiores com 128, 512 e 4096 estrelas.

Mostrar os passos (2)

  1. Você só precisa de 16 estrelas para cada projeto cadastrado em seu nome de usuário. Você pode recebê-los de outros usuários em sua organização ou repositório.

  2. Pronto! Agora você pode ver a conquista Starstruck em sua lista de conquistas.

DifícilPrecisa de outras pessoas

Galaxy Brain

Tenha 2 respostas suas aceitas nas Discussions de um repositório público.

Níveis superiores com 8, 16 e 32 respostas aceitas.

Mostrar os passos (5)

  1. Abra a aba Discussions de qualquer repositório público e escolha a categoria Q&A (ou qualquer outra categoria em que uma resposta possa ser marcada). Respostas no fórum oficial GitHub Community não contam mais, porque o GitHub desativou as conquistas lá.

    Atenção: respostas no fórum Community do próprio GitHub não contam mais. O GitHub desativou as conquistas lá.

  2. Agora você deve encontrar as perguntas não respondidas nas categorias desejadas e respondê-las.

  3. Escreva uma resposta correta para a pergunta (sua resposta deve ser a melhor possível para ser selecionada como a resposta enviada pelo criador da pergunta).

  4. Você precisa ter duas respostas enviadas nas categorias nas quais deseja obter a conquista Galaxy Brain.

  5. Pronto! Agora você pode ver a conquista Galaxy Brain em sua lista de conquistas.

FácilCusta dinheiro

Public Sponsor

Patrocine um desenvolvedor de código aberto pelo GitHub Sponsors.

Mostrar os passos (5)

  1. (Primeiro você deve saber que para conseguir essa conquista você precisa de um cartão de crédito e doar dinheiro). Em seguida, você precisa primeiro abrir a página GitHub Sponsors e depois clicar no botão “See your top dependencies”.

  2. Você verá uma lista de desenvolvedores para os quais pode doar aqui. (Você pode patrocinar qualquer usuário do GitHub que tenha o botão de patrocinador em suas páginas.)

  3. Depois de encontrar a pessoa que deseja patrocinar, você verá uma página para selecionar quanto deseja doar por mês.

  4. Aqui está um formulário de pagamento; Após finalizar o pagamento, você poderá ver sua conquista em seu perfil (na versão Beta, 30 países têm métodos de pagamento disponíveis por enquanto).

  5. Pronto! Agora você pode ver a conquista Public Sponsor na sua lista de conquistas.

Tons de pele 👋🏽

Alguns emblemas, como Quickdraw e Starstruck, seguem o tom de pele dos seus emojis. Mude isso nas configurações de aparência.

Oculte-os se quiser

Não curte emblemas? Você pode desativar as conquistas no seu perfil nas configurações do perfil.

Para as regras oficiais, veja a documentação do GitHub sobre exibir emblemas no seu perfil.

Jogue limpo 🏁

Este guia existe para ensinar como as conquistas funcionam. Respeite os Termos de Serviço do GitHub e as diretrizes da comunidade: não faça spam em outros projetos só para colecionar emblemas. A melhor forma de ganhá-los é participar de projetos reais e ajudar outras pessoas.
