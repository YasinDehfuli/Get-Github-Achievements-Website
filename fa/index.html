دستاوردهای قابل دریافت

هفت نشان که همین امروز می‌توانید بگیرید، از سریع‌ترین تا سخت‌ترین. یک راهنما را باز کنید تا همه مراحل را ببینید.

آسانتنهاییحدود 1 دقیقه

Quickdraw

یک issue یا pull request را ظرف 5 دقیقه بعد از باز کردن ببندید.

نمایش مراحل (4)

  1. شما باید New Issue یا Pull Request را در هر Repository که می خواهید ایجاد کنید.

  2. حالا باید یک عنوان بنویسید و نظر بدهید (در صورت تمایل). و سپس . روی دکمه ارسال شماره جدید کلیک کنید.

  3. هر نظری را که می‌خواهید بنویسید. (می‌توانید موضوع را بدون نظر دادن ببندید) و سپس روی Close issue/close pull request کلیک کنید. (در کمتر از 5 دقیقه باید بسته شود)

  4. تبریک, حالا میتوانید پین Quickdraw را در پروفایل خود مشاهده کنید.

آساننیاز به حساب دوم

YOLO

یک pull request را بدون بازبینی merge کنید، با اینکه از کسی درخواست بازبینی شده.

نمایش مراحل (9)

  1. ابتدا به بخش setting در یکی از ریپازیتوری های خود بروید.

  2. به دسته بندی Collaborators بروید و بر روی دکمه Add People کلیک کنید و در بخش مربوطه اقدام به اینوایت کردن یک اکانت که به آن دسترسی دارید کنید.

  3. یک Branch جدید ایجاد کنید, و روی New Branch کلیک کنید.

  4. بر روی Add file کلیک کنید و وارد بخش Create new file یا Upload file شوید.

  5. فایل خود را آپلود کنید و کامیت برای فایل خود گذاشته و در آخر بر روی دکمه Commit changes کلیک کنید.

  6. بر روی دکمه سبز رنگ Compare & pull request کلیک کنید و تغییرات خود را از برنچ دومی که ساختید به برنچ main انتقال دهید

  7. یک Reviewer که در مرحله دوم آموزش آنرا به پروژه اضافه کردیم اضافه کنید و سپس روی دکمه Create pull request کلیک کنید.

  8. چک کنید Reviewer که در مرحله قبل اضافه کردید در این مرحله هم تنظیم شده باشد. سپس بر روی دکمه Merge pull request کلیک کنید.

  9. تبریک, حالا میتوانید پین Yolo را در پروفایل خود مشاهده کنید.

متوسطنیاز به merge

Pull Shark

2 pull request شما merge شود.

سطح‌های بالاتر با 16، 128 و 1024 pull request ادغام‌شده.

نمایش مراحل (5)

  1. شما باید یک مخزن (هر مخزنی) را انتخاب کنید و از آن یک فورک (Fork) بگیرید

  2. هنگامی که از مخزن فورک گرفتید و فورک شما ایجاد شد ، باید تغییراتی در مخزن فورکی خود ایجاد کنید (هر تغییری مانند افزودن فایل جدید یا انجام برخی تغییرات در کد ها) پس از آن باید به صفحه Pull Request بروید.

  3. بر روی دکمه Pull Request کلیک کنید.

  4. اکنون میتوانید متن سبز رنگی را مشاهده کنید ، که به معنای این است که Pull Request خود را ادغام کنید. بر روی دکمه Create Pull Request کلیک کنید تا درخواست خود را ایجاد کنید.سپس باید منتظر بمانید تا درخواست شما توسط سازنده مخزن ادغام شود.

    برای دریافت این پین ، نیاز است دو درخواست ادغام شده داشته باشید.

  5. کار انجام شد . حالا میتوانید پین Pull Shark را در پروفایل خود مشاهده کنید.

متوسطنیاز به هم‌نویسنده

Pair Extraordinaire

در یک commit از pull requestی که merge می‌شود هم‌نویسنده باشید. هم شما و هم هم‌نویسنده‌تان آن را می‌گیرید.

سطح‌های بالاتر با 10، 24 و 48 pull request ادغام‌شده با هم‌نویسنده.

نمایش مراحل (6)

  1. باید GitHub Desktop را نصب کنید و مخزن خود را از اینترنت کلون کنید. (اگر Error پیدا کردید، باید مخزن خود را از فایل مخزن داخلی خود اضافه کنید)

  2. پیوند HTTPS مخزن خود را کلون کنید و آن را در کادر متنی URL وارد کنید.

  3. نیازی به استفاده از فیلتر باکس نیست فقط بر روی New Branch کلیک کنید و برای مخزن خود Branch جدید ایجاد کنید.

  4. خلاصه‌ای از تغییرات را در کادر عنوان خود اضافه کنید، سپس یک توضیح اضافه کنید، در نهایت یک Co-author با نام کاربری GitHub اضافه کنید (فقط باید یک فایل را در مخزن خود ارسال کنید (فایل‌ها را push نکنید))

    خط فرمان را ترجیح می‌دهید؟ به‌جایش این خط را آخر پیام commit اضافه کنید:Co-authored-by: Their Name <their-email@example.com>

  5. اکنون مخزن خود را در GitHub بررسی کنید و Assignees را اضافه کنید، و سپس بر روی دکمه Merge pull request کلیک کنید (Pair Extraordinaire را به هر دو حساب (شما و Co-Author) می دهد).

  6. کار تمام شد ؛ اکنون میتوانید پین Pair Extraordinaire را در پروفایل خود مشاهده کنید.

سختنیاز به افراد دیگر

Starstruck

مالک مخزنی باشید که به 16 ستاره برسد. اگر بعداً مخزن را منتقل کنید هم حساب می‌شود.

سطح‌های بالاتر با 128، 512 و 4096 ستاره.

نمایش مراحل (2)

  1. شما فقط به 16 ستاره برای هر پروژه ثبت شده در نام کاربری خود نیاز دارید. از سایر کاربران در سازمان یا مخزن خود دریافت کنید.

  2. تبریک, حالا میتوانید پین Quickdraw را در پروفایل خود مشاهده کنید.

سختنیاز به افراد دیگر

Galaxy Brain

در Discussions یک مخزن عمومی، 2 جواب شما پذیرفته شود.

سطح‌های بالاتر با 8، 16 و 32 جواب پذیرفته‌شده.

نمایش مراحل (5)

  1. در مرحله اول به تب Discussions یکی از مخزن‌های عمومی (public repository) بروید و دسته‌بندی Q&A (یا هر دسته‌بندی دیگری که امکان انتخاب پاسخ در آن وجود دارد) را انتخاب کنید. پاسخ‌هایی که در انجمن رسمی GitHub Community داده می‌شوند دیگر حساب نمی‌شوند، چون گیت‌هاب دریافت پین را در آن‌جا غیرفعال کرده است.

    توجه: جواب‌ها در انجمن Community خود GitHub دیگر حساب نمی‌شوند. GitHub دستاوردها را آنجا غیرفعال کرده است.

  2. حال نیاز است از دسته بندی انتخاب شده . به سوالات کاربران پاسخ دهید.

  3. به سوال پرسیده شده پاسخی درست کامل و صحیح بدهید. پاسخ خود را بنویسید و ثبت کنید. (پاسخ شما باید بهترین پاسخ ممکن باشد تا به عنوان پاسخ ارسالی توسط طراح سوال انتخاب شود).

  4. برای دریافت پین Galaxy Brain به دو پاسخ ارسال شده در هر دسته بندی که می خواهید نیاز دارید

  5. تبریک, حالا میتوانید پین Galaxy Brain را در پروفایل خود مشاهده کنید.

آسانهزینه دارد

Public Sponsor

یک توسعه‌دهنده متن‌باز را از طریق GitHub Sponsors حمایت کنید.

نمایش مراحل (5)

  1. (در قدم اول بدانید که برای دریافت این پین به کمک مالی و کارت اعتباری نیاز دارید) . در گام بعدی باید صفحه حامیان مالی گیت هاب را باز کنید و سپس بر روی دکمه مشخص شده کلیک نمایید.

  2. میتوانید در این قسمت فهرستی از توسعه دهندگان را مشاهده کنید.(شما میتوانید به هر یک از کاربرانی که دکمه حمایت مالی دارند ، کمک کنید)

  3. بعد از انتخاب کاربر مورد نظر میتوانید صفحه ایی را مشاهده کنید تا انتخاب کنید در ماه چقدر میخواهید کمک مالی انجام دهید.

  4. پس از پاین پرداخت ، میتوانید نشان خود را در نمایه مشاهده کنید (در نسخه بتا 30 کشور برای روش های پرداخت موجود میباشد)

  5. کار تمام شد ؛ اکنون میتوانید پین Public Sponsor را در پروفایل خود مشاهده کنید.

رنگ پوست 👋🏽

بعضی نشان‌ها، مثل Quickdraw و Starstruck، از رنگ پوست ایموجی شما پیروی می‌کنند. آن را در تنظیمات ظاهر تغییر دهید.

اگر خواستید پنهانشان کنید

از نشان‌ها خوشتان نمی‌آید؟ می‌توانید دستاوردها را از تنظیمات پروفایل خاموش کنید.

برای قوانین رسمی، مستندات GitHub درباره نمایش نشان‌ها در پروفایل را ببینید.

منصف باشید 🏁

این راهنما برای این است که یاد بگیرید دستاوردها چطور کار می‌کنند. لطفاً شرایط استفاده و قوانین جامعه GitHub را رعایت کنید: فقط برای جمع کردن نشان، پروژه‌های دیگران را اسپم نکنید. بهترین راه گرفتنشان، مشارکت در پروژه‌های واقعی و کمک به دیگران است.
