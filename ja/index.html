獲得できる実績

今日から獲得できる 7 つのバッジを、早く取れる順に並べました。ガイドを開くと全ステップが見られます。

簡単ひとりで OK約 1 分

Quickdraw

issue または pull request を開いてから 5 分以内に閉じる。

手順を表示（4）

  1. 好きなリポジトリで新しいイシューまたはプルリクエストを作成する必要があります。

  2. 次に、タイトルを書いてコメントを残します（必要なら）。そして、新しいイシューを提出するボタンをクリックします。

  3. コメントを書いても構いません（コメントなしでイシューやプルリクエストを閉じることもできます）。その後、「イシューを閉じる」または「プルリクエストを閉じる」をクリックします。

  4. 完了しました。これで、アチーブメントリストに「Quickdraw」の達成が表示されます。

簡単2 つ目のアカウントが必要

YOLO

レビュアーをリクエストしたうえで、レビューなしで pull request をマージする。

手順を表示（9）

  1. まず、リポジトリを開き、設定に移動する必要があります。

  2. 次に、共同作業者のカテゴリに移動し、このセクションでリポジトリにアクセスできるアカウントを招待する必要があります。

  3. 三番目に、リポジトリに新しいブランチを追加する必要があります。

  4. 今、作成した新しいブランチにファイルを追加する必要があります。

  5. ファイルを追加し、そのための説明をコミットし、最後に変更をコミットしてください。

  6. 緑色のボタンをクリックして、比較してプルリクエストします。

  7. ステップ2で招待した人をレビュアーとして追加し、プルリクエストを作成します。

  8. 最後に、レビュアーを確認して、プルリクエストをマージするために「Merge pull request」をクリックします。

  9. 完了しました。これで、アチーブメントリストに「Yolo」の達成が表示されます。

普通マージが必要

Pull Shark

2 つの pull request をマージしてもらう。

マージされた pull request が 16、128、1024 でランクアップ。

手順を表示（5）

  1. リポジトリからフォークを作成する必要があります（好きなリポジトリをフォークできます）。

  2. フォークされたリポジトリが作成されたら、フォークされたリポジトリでいくつかの変更を行う必要があります（新しいファイルを追加したり、コードに変更を加えたりします）。その後、プルリクエストタブに移動します；

  3. プルリクエストの作成ボタンをクリックします；

  4. これでマージ可能な緑色のテキストが表示され、これはあなたのプルリクエストをマージできることを意味します。成功裏にプルリクエストを作成するには、「プルリクエストの作成」ボタンをクリックしてください。その後、リポジトリの作成者によってリクエストがマージされるのを待つ必要があります。

    Pull Shark Achievementを取得するには、2つのマージされたプルリクエストが必要です。

  5. 完了しました。これで、アチーブメントリストに「Pull Shark」の達成が表示されます。

普通共同作成者が必要

Pair Extraordinaire

マージされる pull request でコミットを共同作成する。あなたと共同作成者の両方が獲得できます。

共同作成でマージされた pull request が 10、24、48 でランクアップ。

手順を表示（6）

  1. インストールが必要です。 GitHub Desktop , 内部のリポジトリファイルからリポジトリを追加する必要があります。

  2. ローカルリポジトリを追加し、変更したファイルをコミットしてプッシュしてください。

  3. フィルターボックスは使用せず、単に「新しいブランチ」をクリックし、リポジトリ用に新しいブランチを作成してください。

  4. タイトルボックスに要約を追加し、その後に説明を追加し、最後にGitHubのユーザー名で共同著者を追加してください（ファイルをプッシュせずに単にリポジトリにファイルをコミットするだけでよいです）。

    コマンドライン派なら？代わりにコミットメッセージの最後にこの行を追加してください：Co-authored-by: 相手の名前 <their-email@example.com>

  5. GitHubでリポジトリを確認し、担当者を追加し、その後に「プルリクエストのマージ」ボタンをクリックしてください（ペアエクストラディネールは両方のアカウント（あなたと共同著者）に与えられます）。

  6. 完了しました。これで、アチーブメントリストに「Pair Extraordinaire」の達成が表示されます。

難しい他の人が必要

Starstruck

スター 16 個に達したリポジトリを所有する。あとでリポジトリを移管してもカウントされます。

スターが 128、512、4096 でランクアップ。

手順を表示（2）

  1. 各プロジェクトに登録されているユーザー名に対して、他のユーザーや組織からスターを16個受け取るだけです。

  2. 完了しました。これで、アチーブメントリストに「Starstruck」の達成が表示されます。

難しい他の人が必要

Galaxy Brain

公開リポジトリの Discussions で回答を 2 つ採用してもらう。

採用された回答が 8、16、32 でランクアップ。

手順を表示（5）

  1. 任意の公開リポジトリの Discussions タブを開き、Q&A カテゴリ（または回答をマークできる他のカテゴリ）を選択してください。GitHub 公式の Community フォーラムでは実績が無効化されたため、そこでの回答はカウントされなくなりました。

    注意：GitHub 公式の Community フォーラムでの回答はカウントされなくなりました。GitHub がそこでの実績を無効にしています。

  2. 今、回答されていない質問を任意のカテゴリで見つける必要があります。そして、その質問に回答してください。

  3. 質問に正しい回答を記入してください（質問デザイナーによって提出された回答として選択されるためには、あなたの回答が最適なものでなければなりません）

  4. ギャラクシーブレインのアチーブメントを取得するには、任意のカテゴリで提出された回答が2つ必要です。

  5. 完了しました。これで、アチーブメントリストにギャラクシーブレインの達成が表示されます。

簡単費用がかかる

Public Sponsor

GitHub Sponsors でオープンソース開発者をスポンサーする。

手順を表示（5）

  1. (最初に知っておくべきことは、このバッジを取得するにはクレジットカードが必要で、ある金額を寄付する必要があります。) まず、GitHub Sponsors ページを開き、次に「See your top dependencies」ボタンをクリックしてください。

  2. ここで寄付できる開発者のリストが表示されます（スポンサーボタンがあるGitHubユーザーにスポンサーになることができます）。

  3. スポンサーになる相手を見つけたら、月々の寄付額を選択するページが表示されます。

  4. ここで支払いフォームがあり、支払いが完了すると、プロフィールにバッジが表示されます（ベータ版では30か国で支払い方法が利用可能です）。

  5. 完了しました。これで、アチーブメントリストに「Public Sponsor」の達成が表示されます。

フェアプレーで 🏁
