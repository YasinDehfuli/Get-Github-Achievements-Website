अपने GitHub अचीवमेंट्स अनलॉक करें।

पाए जा सकने वाले अचीवमेंट्स

सात बैज जो आप आज ही पा सकते हैं, सबसे जल्दी से सबसे कठिन के क्रम में। हर स्टेप देखने के लिए गाइड खोलें।

आसानअकेले~1 मिनट

Quickdraw

कोई issue या pull request खोलने के 5 मिनट के अंदर उसे बंद करें।

स्टेप दिखाएं (4)

  1. आपको किसी भी रिपॉजिटरी में नया मुद्दा (Issue) या पुल रिक्वेस्ट (Pull Request) बनाना होगा।

  2. अब आपको एक शीर्षक लिखना होगा और एक टिप्पणी छोड़नी है (यदि आप चाहें)। और फिर, "Submit new issue" बटन पर क्लिक करें।

  3. आप जो भी टिप्पणी छोड़ना चाहते हैं (आप बिना टिप्पणी के ही मुद्दा या पुल रिक्वेस्ट को बंद कर सकते हैं)। और फिर "Close issue / close pull request" पर क्लिक करें।

  4. हो गया, अब आप अपनी उपलब्धियों सूची में Quickdraw अचीवमेंट देख सकते हैं।

आसानदूसरा अकाउंट चाहिए

YOLO

रिव्यूअर रिक्वेस्ट होने के बावजूद, एक pull request बिना रिव्यू के मर्ज करें।

स्टेप दिखाएं (9)

  1. सबसे पहले, आपको रिपॉजिटरी खोलनी है और सेटिंग्स पर जाना है।

  2. दूसरे, आपको सहकर्मी श्रेणी में जाना है और इस खंड में, एक ऐसे खाते को आमंत्रित करें जिसे आपको रिपॉजिटरी तक पहुँच है।

  3. तीसरे, आपको अपनी रिपॉजिटरी में एक नई शाखा जोड़नी है।

  4. अब, आपको उस नई शाखा में एक फ़ाइल जोड़नी है।

  5. फ़ाइल जोड़ें और उसके लिए विवरण कमिट करें और अंत में अपने परिवर्तनों को कमिट करें

  6. हरित बटन पर क्लिक करें, समीक्षा और पुल अनुरोध।

  7. चरण-2 में आमंत्रित व्यक्ति को समीक्षक के रूप में जोड़ें, और पुल अनुरोध बनाएं।

  8. आखिरकर, अपने समीक्षक को जांचें और फिर "Merge pull request" पर क्लिक करें।

  9. हो गया, अब आप अपनी उपलब्धियों सूची में Yolo अचीवमेंट देख सकते हैं।

मध्यममर्ज चाहिए

Pull Shark

2 pull request मर्ज करवाएं।

16, 128 और 1024 मर्ज हुए pull request पर ऊंचे लेवल।

स्टेप दिखाएं (5)

  1. आपको किसी भी रिपॉजिटरी से fork लेना होगा (आप किसी भी रिपॉजिटरी को fork कर सकते हैं)।

  2. जब आपकी forked रिपॉजिटरी बन जाए, तो आपको forked रिपॉजिटरी पर कुछ बदलाव करने की आवश्यकता है (नई फ़ाइल जोड़ना या कोड में कुछ बदलाव करना जैसा कुछ भी)। इसके बाद, आपको pull request टैब पर जाना होगा;

  3. create pull request बटन पर क्लिक करें;

  4. अब आप merge कर सकते हैं का हरित पाठ दिखाई देगा, जिसका अर्थ है कि आप अपने pull request को merge कर सकते हैं, इसलिए सफलता से अपना pull request बनाने के लिए Create Pull request बटन पर क्लिक करें। फिर आपको रिपॉजिटरी के निर्माता द्वारा आपकी अनुरोध की प्रतीक्षा करनी होगी।

    पुल शार्क उपलब्धि प्राप्त करने के लिए आपको 2 मर्ज़ युक्त pull request की आवश्यकता है

  5. हो गया, अब आप अपनी उपलब्धियों सूची में पुल शार्क अचीवमेंट देख सकते हैं।

मध्यमको-ऑथर चाहिए

Pair Extraordinaire

किसी ऐसे pull request में commit के को-ऑथर बनें जो मर्ज हो जाए। आप और आपके को-ऑथर दोनों को यह मिलता है।

10, 24 और 48 को-ऑथर किए मर्ज हुए pull request पर ऊंचे लेवल।

स्टेप दिखाएं (6)

  1. GitHub Desktop इंस्टॉल करें, अपने आंतरिक रिपॉजिटरी फ़ाइल से अपनी रिपॉजिटरी जोड़ना है।

  2. एक स्थानीय रिपॉजिटरी जोड़ें और अपनी बदली गई फ़ाइलों को कमिट और पुश करें।

  3. फ़िल्टर बॉक्स का उपयोग करने की आवश्यकता नहीं है, बस "New branch" पर क्लिक करें और अपनी रिपॉजिटरी के लिए एक नई शाखा बनाएं।

  4. अपने शीर्षक बॉक्स में एक सारांश जोड़ें, फिर एक विवरण जोड़ें, अंत में GitHub उपयोगकर्ता के द्वारा सह-लेखक जोड़ें (आपको बस अपनी रिपॉजिटरी में एक फ़ाइल कमिट करनी है (फ़ाइलें पुश न करें))।

    कमांड लाइन पसंद है? इसके बजाय अपने commit मैसेज के आखिर में यह लाइन जोड़ें:Co-authored-by: उनका नाम <their-email@example.com>

  5. अब अपनी रिपॉजिटरी को GitHub पर चेक करें और Assignees जोड़ें, और फिर "Merge pull request" बटन पर क्लिक करें (Pair Extraordinaire दोनों खातों को मिलेगा (आप और सह-लेखक))।

  6. हो गया, अब आप अपनी उपलब्धियों सूची में पेयर एक्स्ट्रा-डिनेयर उपलब्धि देख सकते हैं।

कठिनदूसरे लोग चाहिए

Starstruck

ऐसी repository के मालिक बनें जिसे 16 स्टार मिलें। बाद में repository ट्रांसफ़र करने पर भी यह गिना जाता है।

128, 512 और 4096 स्टार पर ऊंचे लेवल।

स्टेप दिखाएं (2)

  1. आपको अपने उपयोगकर्ता नाम पर पंजीकृत प्रत्येक परियोजना के लिए केवल 16 स्टार की आवश्यकता है। अपने संगठन या रिपॉजिटरी पर अन्य उपयोगकर्ताओं से प्राप्त करें।

  2. हो गया, अब आप अपनी उपलब्धियों सूची में Starstruck अचीवमेंट देख सकते हैं।

कठिनदूसरे लोग चाहिए

Galaxy Brain

किसी पब्लिक repository के Discussions में अपने 2 जवाब स्वीकार करवाएं।

8, 16 और 32 स्वीकार किए गए जवाबों पर ऊंचे लेवल।

स्टेप दिखाएं (5)

  1. किसी भी सार्वजनिक (public) रिपॉजिटरी के Discussions टैब पर जाएँ और Q&A श्रेणी (या कोई भी अन्य श्रेणी जिसमें उत्तर को चिह्नित किया जा सकता है) चुनें। GitHub के अपने Community फ़ोरम में दिए गए उत्तर अब नहीं गिने जाते, क्योंकि GitHub ने वहाँ उपलब्धियाँ बंद कर दी हैं।

    ध्यान दें: GitHub के अपने Community फ़ोरम के जवाब अब नहीं गिने जाते। GitHub ने वहां अचीवमेंट्स बंद कर दिए हैं।

  2. अब आपको जितनी भी श्रेणियों में चाहें, वहां अनुत्तरित प्रश्नों को ढूंढना है। और प्रश्नों का उत्तर देना है।

  3. सवाल का सही उत्तर लिखें (आपका उत्तर प्रश्न डिज़ाइनर द्वारा प्रस्तुत उत्तर के रूप में चयन होने के लिए सबसे अच्छा उत्तर होना चाहिए)।

  4. गैलेक्सी ब्रेन अचीवमेंट प्राप्त करने के लिए आपको दो प्रस्तुत किए गए उत्तरों की आवश्यकता है।

  5. हो गया, अब आप अपनी उपलब्धियों सूची में गैलेक्सी ब्रेन अचीवमेंट देख सकते हैं।

आसानपैसे लगते हैं

Public Sponsor

GitHub Sponsors के ज़रिए किसी ओपन-सोर्स डेवलपर को स्पॉन्सर करें।

स्टेप दिखाएं (5)

  1. (सबसे पहले आपको यह जानना होगा, इस बैज प्राप्त करने के लिए आपको क्रेडिट कार्ड और कुछ धन दान करना होगा)। तब आपको पहले GitHub सपोंसर्स पृष्ठ खोलना है, और फिर "See your top dependencies" बटन पर क्लिक करें।

  2. यहां आप उन डेवेलपर्स की सूची देख सकते हैं जिन्हें आप यहां धन दान कर सकते हैं (आप उन GitHub उपयोगकर्ताओं के सपोंसर बटन के साथ जो धन दान कर सकते हैं)।

  3. जब आपने सपोंसर करने वाले व्यक्ति को खोज लिया है, तो आपको महीने भर में कितना दान करना चाहते हैं, इसे चुनने के लिए एक पृष्ठ दिखाई देगा।

  4. यहां एक भुगतान के लिए एक फॉर्म है, जब आपका भुगतान समाप्त हो जाएगा, तो आप अपने प्रोफ़ाइल में अपने बैज देख सकते हैं (बीटा संस्करण में 30 देशों के लिए अब भुगतान के तरीके हैं)।

  5. हो गया, अब आप अपनी उपलब्धियों सूची में पब्लिक सपोंसर अचीवमेंट देख सकते हैं।

स्किन टोन 👋🏽

कुछ बैज, जैसे Quickdraw और Starstruck, आपकी इमोजी स्किन टोन के हिसाब से बदलते हैं। इसे अपनी appearance सेटिंग्स में बदलें।

चाहें तो इन्हें छिपाएं

बैज पसंद नहीं? आप अपनी प्रोफ़ाइल सेटिंग्स से प्रोफ़ाइल पर अचीवमेंट्स बंद कर सकते हैं।

आधिकारिक नियमों के लिए, GitHub के डॉक्स में प्रोफ़ाइल पर बैज दिखाना देखें।

ईमानदारी से खेलें 🏁

यह गाइड आपको यह सिखाने के लिए है कि अचीवमेंट्स कैसे काम करते हैं। कृपया GitHub की सेवा की शर्तों और कम्युनिटी गाइडलाइंस का सम्मान करें: सिर्फ़ बैज जमा करने के लिए दूसरे प्रोजेक्ट्स पर स्पैम न करें। इन्हें पाने का सबसे अच्छा तरीका है असली प्रोजेक्ट्स में हिस्सा लेना और दूसरों की मदद करना।
